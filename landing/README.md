# Приватный preview лендинга Aheadscale

Статическая страница без сборки и без серверных зависимостей. Макет и границы:
`headscale/docs/superpowers/specs/2026-10-31-landing-preview-design.md`.

Для локального просмотра: `python3 -m http.server 4173 --bind 127.0.0.1 --directory landing`.
Каталог следует отдавать только как статику; API, OAuth и кабинет не меняются.

`manifest.json` — снимок действующего `/downloads/beta/manifest.json` для
приватного просмотра. Он не разрешает выпуск: сейчас `releaseReady=false` и
`packages=[]`. Смена источника на живой путь и публичное размещение относятся
к отдельной задаче маршрутов AHEAD-22. Не править флаг допуска ради показа кнопок.

Ссылки создаются только для корректного beta-манифеста с явным допуском.
Глобальная версия `clientVersion` или версия пакета обязательна, SHA256 — 64 hex,
размер — положительное целое, платформа/архитектура/формат проверяются. HTTPS
только `aheadscale.ru/downloads/`, без учётных данных, query и fragment.
Постоянные preview-адреса байтов допустимы после явного допуска в beta-манифесте;
сам preview-манифест загрузок не разрешает.

Тесты: отдельный workflow `Aheadscale landing preview` в приватном репозитории
`pomozoff/aheadscale-tests`, закреплённый SHA кандидата. Используется уже имеющаяся
браузерная среда `auth`, без добавления зависимостей. Проверки не собирают VPN-клиенты.
Артефакт содержит статический сайт, SHA256SUMS, исходный commit и снимки обеих тем.
Поддержка и документы добавляются после их отдельной проверки.
