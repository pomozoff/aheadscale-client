# Опытный системный VPN Windows

Отдельный ARM64-пакет для проверки архитектуры на собственной Windows 11 VM. Не распространять пользователям. Исходный клиент `.8`, его служба и Wintun не заменяются.

Сборка: `scripts/build.ps1 -Architecture arm64 -SdkVersion 10.0.26100.0`. Нужны Windows SDK 10.0.26100.0, MSVC v143, CMake и PowerShell 7. Артефакт содержит подписанный MSIX, публичный `.cer`, SHA256 и скрипты установки/отката. Закрытый ключ не экспортируется и удаляется со сборочного runner.

`install-test.ps1` запускается администратором **от имени владельца VM**. Он проверяет хеш, издателя и подпись, добавляет только опытный публичный сертификат в TrustedPeople и устанавливает пакет для текущего пользователя. Trusted Root, Defender, UAC и настройки обновления не изменяются.

Команды пакетного контроллера `aheadscale-vpn-prototype.exe`: `add`, `status`, `connect`, `disconnect`, `remove`. Дополнительные `broker` и `probe` проверяют границу процессов. Посредник ждёт один запрос максимум 90 секунд. Он проверяет фактические Package Family Name, SID пользователя и AppContainer SID вызывающего, после чего обращается к существующему защищённому IPC и выполняет штатный RPC status. Полномочия службы не расширяются. Непакетный процесс либо другой пользователь отклоняются.

На первом этапе **Connect намеренно завершается ошибкой даже после успешной проверки IPC**: канал IP-пакетов ещё не реализован. Это не рабочая VPN-интеграция. Диагностика `vpn-plugin.json`, `vpn-background.json`, `broker.json` находится в LocalState пакета; токены, ключи и IP-пакеты не записываются.

Откат: `remove-test.ps1`. Он сверяет квитанцию `%LOCALAPPDATA%\AheadscaleVpnPrototype\install.json`, удаляет принадлежащий пакету профиль, пакет и только добавленное при установке доверие. Рабочая регистрация обычного Aheadscale сохраняется.
