# Единый план проверок и стенд Windows 11 x64

> Исполнение: один агент в текущем сеансе по навыку `superpowers:executing-plans`; без делегирования.

**Цель:** собрать существующие проверки Aheadscale в единый русскоязычный план и подготовить на Mac mini работающую Windows 11 x64 с закрытым RDP-доступом.

**Основание:** запрос владельца от 23 октября 2026; ранее выбран нативный QEMU/KVM на Ubuntu, одна активная настольная ВМ, 2 vCPU, 8 ГБ памяти, диск 80 ГБ.

**Решение:** отдельная рабочая ветка документации; исходные отчёты сохраняются. ВМ запускается непривилегированным QEMU/KVM, с UEFI Secure Boot, TPM 2.0 и пользовательской NAT-сетью без изменения маршрутов Docker. ISO берётся у Microsoft; RDP доступен через Tailscale, с NLA и отдельной локальной учётной записью. Образ Evaluation имеет срок оценки 90 дней.

## Ограничения

- Документы на русском; незавершённые изменения другой рабочей копии не включать в коммит.
- Исторический PASS относится только к указанной сборке и окружению. Общий релизный кандидат ещё не проверен.
- Не собирать клиенты заново, не публиковать пакеты и не менять сервер регистрации в этой задаче.
- Не изменять работающие сервисы, Docker, маршрутизатор и существующие правила Tailscale Serve.
- Пароли и установочный файл с паролем не помещать в Git и журналы.

## Что проверить особенно внимательно

- Старые отчёты содержат как первые отказы, так и успешные повторные прогоны: сохранить оба.
- Connected без DNS и прикладного трафика не доказывает рабочий туннель.
- Опытный Windows VPN и обычный установщик — разные комплекты.
- macOS без Network Extension не получает системный профиль VPN.
- Доступный RDP-порт ещё не доказывает успешную авторизацию и рабочий стол.

## Задача 1. Документация

1. Перенести исторические отчёты без изменения результатов; составить индекс доказательств.
2. Создать общий вход `docs/aheadscale/smoke-test-plan.md`, отдельные сценарии UI/CLI и карту регрессий.
3. Переписать устаревшую приёмку на русском с ссылкой на общий план и сохранить происхождение ранних CI-сборок.
4. Проверить относительные ссылки, наличие названных исходников и `git diff --check`; подписать коммит и перенести в локальный `main`.

## Задача 2. Стенд Windows

1. Скачать официальный ISO, сохранить источник и SHA256 на диске хоста.
2. Подготовить QEMU/KVM, отдельный qcow2, UEFI, TPM и установочные настройки Windows.
3. Установить Windows, включить RDP с NLA, проверить редакцию, архитектуру и успешный вход.
4. Сохранить паспорт стенда без секретов и закрытый файл доступа; передать владельцу адрес RDP.

## Проверка результата

Документация: корректные ссылки и чистый diff. ВМ: установленная Windows x64, успешная проверка RDP и отсутствие публичного слушателя RDP. Подготовка ОС не засчитывается как smoke клиента Aheadscale.
