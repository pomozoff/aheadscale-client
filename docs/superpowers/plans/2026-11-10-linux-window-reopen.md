# AHEAD-68: безопасное повторное открытие Linux GUI

> **For agentic workers:** REQUIRED SUB-SKILL: использовать superpowers:executing-plans; один агент по решению владельца.

**Goal:** убрать конфликтующий Linux-интерфейс SIGUSR1 и сохранить штатное открытие через SingleInstance/tray.
**Architecture:** Linux не регистрирует обработчик сигнала; повторный запуск использует уже существующий callback. macOS и Windows сохраняют свои обработчики.
**Tech Stack:** Go/Wails, GTK4/WebKitGTK, GitHub Actions, существующая Kubuntu-ВМ.
**Spec:** `/home/adnako/Developer/headscale/docs/releases/2026-11-09-ahead68-window-reopen-design.md`; дизайн согласован владельцем.

## Ограничения

- Не посылать SIGUSR1 в GUI при проверке; это больше не публичная команда Aheadscale.
- Не использовать signal.Ignore/блокировку/перенастройку WebKit GC.
- Не менять D-Bus, авторизацию, сетевой контроллер, зависимости приложения.
- Сборки/продуктовые тесты — в Actions; установленное приложение проверяется отдельно.

## Review Focus

- Linux-файлы не должны регистрировать/перехватывать SIGUSR1.
- Callback повторного запуска вызывает штатный показ окна.
- macOS/Windows не теряют существующий способ открытия.
- Скрытие окна не завершает основной процесс и VPN.
- Тестовые инструкции не предлагают исключённый сигнал.
