# Windows ARM64: завершение оставшихся сценариев .23.1

Основание: согласованная очередь продолжения и запрос владельца «Завершай Windows ARM». Один агент; ранее принятые CLI/сеть/служба и enabled reinstall не повторяются целиком.

1. Проверить реальные Connect/Disconnect в Windows Settings, включая отмену в Connecting; сравнить GUI, CLI, native VPN, адреса, отрицательный трафик/обычный интернет и T01 после восстановления.
2. Полное remove/reinstall с явно выключенным запуском GUI; сохранить SHA256 трёх конфигураций, регистрацию и отсутствие Task/Run. Фактическая новая загрузка и вход без ручного запуска: GUI не появляется, VPN остаётся отключённым.
3. Через GUI включить запуск приложения при входе и выключить Connect on Startup; проверить установку поверх и новую загрузку: GUI запущен, сеть отключена. Вернуть исходные настройки и рабочее соединение, выполнить финальный T01.
4. Удалить собственные временные процессы, правила, задачи, копии EXE и рабочие файлы; отчёт/матрицу подписанно перенести в main.

Границы: не изменять сервер, устройства аккаунта, Windows Update, Defender/UAC и подписи. Время загрузки ОС не измерять как Connect. Новый исходный код/сборка нужны лишь при доказанном функциональном дефекте; TDD применяется к такому исправлению, а не к повторному созданию уже существующих тестов. Публичная подпись остаётся внешней зависимостью; чистая установка в отдельном состоянии и вся матрица не становятся PASS по этим трём сценариям.

Ruling: штатное получение рабочих копий через приложение не ответило и остановлено; используются отдельные git worktree по действующему правилу Developer/AGENTS.md. Свежий внешний reviewer не вызывается: владелец явно требует одного агента.
