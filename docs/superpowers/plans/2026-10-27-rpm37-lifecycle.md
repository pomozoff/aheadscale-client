# Исправление RG37: план выполнения

> Для исполнения: superpowers:executing-plans, одним агентом по указанию владельца.

**Цель:** исправить ранее воспроизведённый RG37, сохраняя регистрацию и включённость/активность systemd-службы при Desktop ↔ CLI RPM, включая переход со старой `.24`.

**Основание:** согласованные C13/RG37 в cli-test-plan.md и прямое поручение «Исправляй дефект». Это восстановление требуемого поведения установщика. Новые UI/CLI-возможности, сервер и ключи не менять.

**Решение:** сохранить состояние перед транзакцией в закрытом временном каталоге `/run`, восстановить в `%posttrans` после старого `%preun`. Не запускать службу в промежуточном `%post`; при свежей установке запускать по прежнему правилу. Обычное окончательное удаление по-прежнему очищает только своё подключение. Альтернатива с проверкой второго RPM только в `%preun` не чинит уже выпущенную `.24`; безусловный enable в конце отменяет отключённый пользователем автозапуск.

- [x] Регрессия реальных shell hooks: старое удаление выключает службу; конечные состояния active/enabled и inactive/disabled, смешанные состояния, первая установка. Сначала RED.
- [x] Минимальное исправление spec и общих shell-функций, без изменения конфигурации/ключей. GREEN; make lint и профильные packaging-тесты.
- [x] Собрать новые RPM без повторной компиляции неизменившихся CLI/UI; отдельная revision RPM и манифест исходника упаковки/хешей прежних бинарников.
- [x] Fedora: `.24` Desktop → исправленный CLI → Desktop; обновление того же варианта, остановленная/отключённая служба, постоянное отключение автосоединения и удаление/переустановка. Проверить регистрацию, NM и T01, вернуть рабочий Desktop.
- [x] Обновить русские отчёты/RG37; проверенные подписанные изменения перенести в main. Никакой публикации или изменения канала обновлений.

Важная граница: временный `down` хранит намерение в памяти процесса; постоянная настройка `DisableAutoConnect` хранится в конфигурации. Отдельно зафиксировать оба поведения при restart, не подменять их одним обещанием сохранения systemd active/enabled.
