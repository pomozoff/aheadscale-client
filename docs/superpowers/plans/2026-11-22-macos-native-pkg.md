# AHEAD-18: план выпуска PKG macOS ARM64

Согласованный дизайн: headscale, docs/releases/2026-11-22-macos-native-pkg-design.md (0c090a4). Один исполнитель.

1. Добавить режим установленного приложения и постоянной службы, сохранив изоляцию прототипа. Проверить запуск GUI, ограниченный headless-протокол, штатный старт daemon без регистрации и системное удаление собственного профиля.
2. В отдельном workflow собрать payload PKG ARM64 и проверить состав, идемпотентность скриптов, отказ на чужом layout и откат. Старый упаковщик macOS, Linux и Windows оставить без изменений.
3. Подписать вложенный код, приложение и PKG на MacBook, принять тикет Apple и проверить SHA-256. С нуля установить в ARM64 ВМ, дать штатные разрешения, пройти браузерный вход, проверить GUI/CLI/системный VPN, ранний Cancel и двусторонний HTTP с одним узлом по IP и имени.
4. Проверить перезапуск, переустановку, обновление с сохранением прежней регистрации и удаление. При отказе сохранить факты и отменить переход релизной карточки.
