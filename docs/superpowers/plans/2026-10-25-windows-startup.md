# Ускорение пользовательского запуска Windows

Причина подтверждена: штатная запись Run запускает UI через 61,04 с после
входа. Контрольная задача с InteractiveToken/Limited запускает тот же EXE
через 1,39 с; ожидание собственного VPN после раннего старта проверяется отдельно.

Выбор реализации: собственная задача при входе текущего пользователя. Глобальные
параметры Windows не меняются. Переключатель UI становится фасадом над задачей;
обычные сборки сохраняют Wails/Run. Миграция переносит только свою включённую
запись Run и удаляет её после успешного создания задачи. Выключенный автозапуск
не включается. Повторный вызов идемпотентен; чужая/изменённая задача не заменяется.

Один встроенный PowerShell-модуль обслуживает UI и удаление/обновление пакета.
Задача запускает только установленный native UI без повышения прав и пароля.
Проверяются SID, путь, аргументы, тип триггера и уровень прав; отказ по умолчанию.
Обновление сохраняет текущий выбор, удаление убирает только свою задачу.
