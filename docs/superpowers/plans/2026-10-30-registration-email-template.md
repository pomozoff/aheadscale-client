# Фирменное письмо регистрации Aheadscale

> Исполнение одним агентом через `superpowers:executing-plans`, без делегирования.

**Цель:** подключить утверждённый макет к реальной отправке регистрации.
**Архитектура:** встроенные HTML/text-шаблоны, стандартный Go MIME
`multipart/alternative`, quoted-printable и экранирование `html/template`.
SMTP/TLS, выдача токена и проверка адреса сохраняют прежний порядок.
**Основание:** [утверждённый дизайн](../../aheadscale/designs/registration-email.md).

## Ограничения

- Реальные адрес, ссылка и TTL из настроек; без демонстрационных значений.
- Текстовая часть и запасная ссылка обязательны, пароль в письме отсутствует.
- Сборка и тесты в GitHub Actions, только пакет регистрации и серверный образ.
- Ключи Postbox не попадают в Actions. Без новых зависимостей Go.
- Обновлять только сервер на Mac mini; сохранять данные, SMTP и материал отката.

## Что проверяем отдельно

Кодирование MIME не должно менять токен, экранирование — создавать HTML-вставки,
переменный срок — расходиться с серверным TTL. Изменённая вёрстка не означает
проверенную визуальную совместимость со всеми почтовыми клиентами.
Реальные письма не отправлять автоматически без отдельного согласования.
