# RG22: сохранить выбор автозапуска при переустановке Windows

> Исполнение: один агент, `superpowers:executing-plans`, без делегирования.

**Цель:** полное удаление убирает системный автозапуск, повторная установка возвращает прежний включённый или выключенный выбор без потери регистрации.
**Основание:** C13/RG22 существующих тест-планов; живой FAIL `.23`: после remove/reinstall нет ни задачи, ни Run; после входа нет GUI, VPN Idle. Установка поверх и следующий вход на `.23` прошли.
**Решение:** общий `client/internal/windowsstartup/task.ps1` сохраняет текущий проверенный выбор в пользовательском DWORD `HKCU\Software\Aheadscale\DesktopInstallerStartupV1:Enabled` при операции remove. Новая операция restore восстанавливает только собственную задачу/Run из этого флага. Установщик вызывает restore после размещения native UI. Системные записи при удалении очищаются; сохраняется только пользовательский выбор. Нет записи — прежнее поведение первой установки. Выключенный/заблокированный Windows выбор не превращается во включённый.
**Технологии:** существующие PowerShell, Task Scheduler, HKCU и NSIS; CLI/UI/MSIX `.23` не пересобираются, источник бинарников отделяется от исправления упаковки.

## Ограничения и проверка

- Проверять владельца и точный путь задачи/Run до сохранения и изменений; не принимать чужую запись или повреждённый DWORD, не повышать права задачи. Флаг не хранит секретов, не переносится между пользователями.
- Тесты используют случайный TestSuffix и очищают только свои задачи/значения. UI state/inspect не восстанавливает флаг самостоятельно: намеренное выключение не отменяется.
- Не менять сеть, подписи, сертификаты, обновления Windows или серверную политику. Не измерять скорость загрузки ОС.
