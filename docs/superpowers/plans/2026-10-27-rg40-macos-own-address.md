# План исправления RG40 на macOS

> **Для исполнителя:** применять superpowers:executing-plans, выполнять одним агентом.

**Цель:** HTTP и ICMP к собственному VPN-IPv4 работают без остаточного маршрута.
**Архитектура:** отдельный selfroute хранит намерение в statemanager до изменения
маршрута, проверяет принадлежность и удаляет только своё изменение. Darwin TunDevice
вызывает его при назначении/смене адреса и закрытии; сервер регистрирует тип восстановления.
**Стек:** Go 1.26.7, существующий x/net/route, штатная утилита /sbin/route.
**Спецификация:** ../specs/2026-10-27-rg40-macos-own-address.md.

## Ограничения

- Согласованный вариант lo0 + собственный исходный IPv4; без новых зависимостей.
- Только собственный /32 на macOS; не изменять IPv6, firewall, sysctl и RG39.
- Все новые документы на русском; сборка только macOS ARM64 preview.
- Сохранить регистрацию устройства, существующие службы и чужие маршруты.

## Фокус проверки

- Чужой либо изменённый маршрут: не удалять и не перезаписывать.
- Ошибка записи журнала: изменение маршрута не начинается.
- Падение между записью намерения и изменением: повторная уборка безопасна.
- Неудачная уборка: запись сохраняется, Close всё равно закрывает устройство.
- Удалённый UTUN после аварии: убрать помеченный lo0 /32 и подключиться снова.
