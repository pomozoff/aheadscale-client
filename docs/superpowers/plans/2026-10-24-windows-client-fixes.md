# Исправления Windows-клиента Aheadscale

> Выполнение: один агент, в текущем сеансе; `superpowers:executing-plans`.

**Цель:** устранить подтверждённые дефекты x64 preview и проверить новый
установщик на уже зарегистрированной ВМ без потери устройства.

**Основание:** [отчёт smoke](../../aheadscale/smoke-results/2026-10-24-windows11-x64-smoke.md).
**Подход:** изолированная рабочая копия, воспроизведение → минимальное
исправление → тот же runtime-повтор; Go 1.26.7, существующие Wails/NSIS.
Зависимости, протокол IPC, сервер регистрации и опытный native VPN не меняются.

## Итог и ограничения

Код: `6f62167`; [результаты повтора](../../aheadscale/smoke-results/2026-10-24-windows11-x64-fixes.md).
Прогон завершён в согласованном объёме исправлений. Windows DACL-тесты,
unit suite и установленный `.10` проверены. Ускорение reboot не доказано:
38,42 с после готовности RDP, общий бюджет T03 всё ещё FAIL. Системный native
VPN и полная приёмка UI/CLI остаются отдельной работой. Подписи публичного
установщика нет. Фактическая проверка success/error callback нового пакета
не выполнялась; включение актуального шаблона подтверждено исходником и тестами.

Отдельная визуальная проверка Generate Bundle / Reveal из GUI остаётся NOT_RUN;
доступный ZIP и отсутствие необходимости UAC проверены CLI и общим экспортом.
