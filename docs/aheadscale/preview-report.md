# Клиент Aheadscale: тестовые сборки

Исходная точка: NetBird v0.80.0, commit
`fca64287cf51a85552a41b022013abbfdb335452`.
Публичный форк: https://github.com/pomozoff/aheadscale-client.
Основная ветка форка: `aheadscale`; рабочая ветка реализации: `codex/aheadscale-client`.

## Реализация

Клиент получил имя, значок и оформление Aheadscale. Первый экран предлагает вход
или регистрацию через браузер; выбор Cloud/Self-hosted и редактирование сервера
из обычного сценария убраны. Существующее завершение SSO в Go продолжает
подключение даже при скрытом окне. Автоподключение и регистрация сохраняются
штатным механизмом клиента; работа после реальной перезагрузки ещё проверяется.

Пакеты используют собственные службы, каталоги, IPC и интерфейсы, отдельные
firewall/routing/conntrack идентификаторы и порт UDP 51830. Файлы NetBird и
Tailscale не мигрируются. `NB_CONFIG`/`WT_CONFIG` не выбирают профиль Aheadscale:
для флагов предназначен префикс `AS_`. Тестовые обновления и отправка диагностики
в upstream выключены; BSD LICENSE и notices сохранены.

Внутренние сборки закреплены за `https://macmini.tailb71cbe.ts.net:10443`,
публичная конфигурация — за `https://aheadscale.ru:443`. Официальный процесс
сборки встраивает ограничение адреса: профиль другого окружения отклоняется без
перезаписи ключей, переноса регистрации или переключения аккаунта. MDM не может
перенаправить такой клиент в другое окружение.

Один desktop-пакет содержит службу и UI. Предусмотрены Linux amd64/arm64 desktop/CLI, Windows amd64/arm64 NSIS и macOS Apple Silicon (arm64) pkg.
По уточнению пользователя macOS Intel и остальные архитектуры пока отложены.
macOS включает отдельное удаление только Aheadscale; данные регистрации
сохраняются. Windows сохраняет данные, пока пользователь явно не выберет их
удаление. Целевые системы и необходимые библиотеки описаны в README клиента.

## Сборка и проверки

Версии Go, Node, pnpm, Wails и исходный commit закреплены в manifest; GitHub
Actions также закреплены по SHA. Workflow создаёт только временные CI artifacts.
Ключей подписания, загрузки на CDN и публикации releases в нём нет. Upstream
workflows сохранены в архивном каталоге и не исполняются в форке.

Локально прошли штатные тесты CLI, профилей, IPC/прав, packet marks и системных
маршрутов. Регрессионные тесты подтвердили прежнюю проблему и исправление для
настроенного сервера, конфликтующих marks, переменных другого продукта и
профиля другого окружения. Прошли ESLint без предупреждений, проверка ключей
переводов и actionlint. Штатный процесс собрал Linux arm64 CLI .deb; сборка не
устанавливает клиент на рабочем Mac mini.

Linux amd64 desktop/CLI .deb собраны штатным процессом в изолированной Ubuntu.
Прошли TypeScript/Vite, штатные тесты UI-служб и диагностики. Системный клиент
Windows amd64 и тест отдельного GUID адаптера скомпилированы; запуск на Windows
включён в CI. Подпись Git-коммитов выполняется GitHub через createCommitOnBranch,
настройки подписи Git и личные ключи владельца не изменяются.

Готовые тестовые установщики: [GitHub Actions 39022500060](https://github.com/pomozoff/aheadscale-client/actions/runs/39022500060),
исходный commit `b9f43a05d0cd8d4f71b5650fc53037ad6f539e7f`.

| Платформа | Результат CI |
| --- | --- |
| Linux amd64 desktop и CLI | Passed; установка, запуск службы и удаление на runner |
| Windows amd64 | Passed; NSIS installer |

Общий запуск отменён из-за задачи macOS Intel; перечисленные выше три задачи
успешно завершились, их артефакты доступны. Повторные сборки после изменения
матрицы остановлены: изменение списка платформ не требует пересобирать уже
готовые пакеты. Режим CI `current` сохраняет Windows amd64, Linux amd64 и macOS arm64;
дополнительный режим `arm64` собирает только Windows/Linux arm64.

- [Windows amd64](https://github.com/pomozoff/aheadscale-client/actions/runs/39022500060/artifacts/12097407780)
- [Linux amd64](https://github.com/pomozoff/aheadscale-client/actions/runs/39022500060/artifacts/12097097442)
- [macOS arm64](https://github.com/pomozoff/aheadscale-client/actions/runs/39022500060/artifacts/12096949045)

Тесты конфигурации/IPC/изоляции, запрета upstream-обновлений, нативного GUID
адаптера Windows и UI-служб Linux прошли. Артефакты содержат оба окружения
(`internal` и `public`) и SHA256SUMS; срок хранения — семь дней. Для проверки
собственных ВМ через интернет нужен `public`. Сервер на Mac mini и OAuth теперь
настроены на `https://aheadscale.ru`; на ВМ Tailscale не требуется. Вход выполняется
существующим аккаунтом владельца. `internal` сохраняет прежний адрес Tailscale
и для этого сценария не подходит. Клиенты при переключении сервера не пересобирались.

HTTPS/OAuth, сохранность аккаунта и отказ неавторизованного API проверены с Mac mini.
Публичный setup закрыт. Внешняя доступность, вход с ВМ и полезный обмен между двумя
ВМ ожидают проверки владельцем; публичный пользовательский сервис не объявлен готовым.

Сбой подготовки pnpm на Intel устранён установкой точной версии 11.4.0 через
npm, без переключения версии сторонним bootstrapper. Проверка изоляции также
выявила остаточный `NB_STATE_DIR`: теперь каталог состояния задаёт только
`AS_STATE_DIR`. Подсказки CLI предлагают команды Aheadscale и не требуют ввода
адреса сервера.

## Условия внешнего запуска

В репозитории клиента `docs/aheadscale/acceptance.md` содержит отдельные шаги
проверки каталога устройств, offline, поиска/копирования IP и имени, системного
DNS, полезного SSH/HTTP, reboot/upgrade/uninstall и сохранности NetBird/Tailscale.
Результаты на чистых ОС пока Pending.

17 октября 2026 GET `/api/instance` приватного стенда вернул
`setup_required=false`: первичная настройка выполнена. Это не подтверждает
саморегистрацию пользователей, MFA, отдельную сеть каждого аккаунта,
серверный лимит пяти устройств или изоляцию каталога/DNS/трафика. Эти проверки
остаются обязательными, как и собственный подписанный канал обновлений, CDN,
Windows publisher certificate и Apple Developer ID/нотариализация.

До выполнения условий installers предназначены только для собственных испытаний.


## Проверка входа Linux ARM64 — 18 октября 2026

На Ubuntu ARM64 подтверждены вход по email через Firefox, регистрация устройства,
состояние Connected, подключение к management/signal и интерфейс as0 с приватным
IPv4 и именем в aheadscale.internal. Второго устройства пока нет; обмен трафиком
между устройствами, разрешение приватных имён и перезагрузка ещё не проверены.
Предыдущие попытки входа завершались по пятиминутному тайм-ауту приёмника OAuth;
свежая попытка через Connect в графическом клиенте прошла без изменения авторизации.

Встроенная страница возврата localhost теперь использует название, знак и favicon
Aheadscale на экранах успеха и ошибки. Существующие тесты шаблона и проверка
отображения Chromium в размерах 1280×900 и 390×844 прошли. Пакет Linux ARM64
0.80.0-aheadscale.2 собран локально с Go 1.26.7: пересобрана служба, неизменённый UI
взят из проверенного desktop-пакета 0.80.0-aheadscale.1. Контрольная сумма,
архитектура и запуск нового CLI проверены на пользовательской ВМ. Установщик
передан в Downloads и установлен владельцем. Версия службы .2 подтверждена;
повторное подключение сохранило регистрацию, прежний IPv4 и приватное имя.
После установки потребовался Connect; автоматическое подключение после обновления
и перезагрузки ещё требует отдельной проверки.
Установщики Windows и macOS на этом этапе повторно не собирались.


## Дополнительный аудит брендинга — 18 октября 2026

Проверены встроенные страницы PKCE, формы Dex, строки интерфейса и CLI,
переводы и изображения. Найденные пропуски исправлены для версии
0.80.0-aheadscale.3:

- Два SVG-исходника значков меню и ожидания входа заменены знаком Aheadscale.
  Эти исходники хранятся для справки; текущая сборка использует PNG, которые уже
  были заменены. Исправлено обрезание названия в двух полных SVG-логотипах UI.
- Ссылки на установщики и инструкции NetBird на экранах недоступной/старой службы
  и в подсказках CLI ведут к Aheadscale.
- Примеры адресов сервера в 11 переводах используют aheadscale.ru.
- Исправлены подписи IP в текстовом статусе, ошибки настройки входа и SSH,
  уведомления, системный запрос macOS и заголовки диагностических данных.

Правовые уведомления и названия протокольных/внутренних идентификаторов сохранены.
Существующие тесты статуса обновлены; в Linux-тесте уведомлений явно включён
тестовый механизм по образцу Windows/macOS. Проверка запрета upstream-обновлений
Aheadscale сохранена. Базовая ветка make lint приведена к origin/aheadscale;
LINT_BASE позволяет выбрать другую базу. Результаты сборки ARM64 фиксируются
отдельно от проверки исходников.
