# Клиент Aheadscale: тестовые сборки

Исходная точка: NetBird v0.80.0, commit
`fca64287cf51a85552a41b022013abbfdb335452`.
Публичный форк: https://github.com/pomozoff/aheadscale-client.
Рабочая ветка клиента: `codex/aheadscale-client`.

## Реализация

Клиент получил имя, значок и оформление Aheadscale. Первый экран предлагает вход
или регистрацию через браузер; выбор Cloud/Self-hosted и редактирование сервера
из обычного сценария убраны. Существующее завершение SSO в Go продолжает
подключение даже при скрытом окне. Автоподключение и регистрация сохраняются
штатным механизмом клиента; работа после реальной перезагрузки ещё проверяется.

Пакеты используют собственные службы, каталоги, IPC и интерфейсы, отдельные
firewall/routing/conntrack идентификаторы и порт UDP 51830. Файлы NetBird и
Tailscale не мигрируются. `NB_CONFIG`/`WT_CONFIG` не выбирают профиль Aheadscale:
для флагов предназначен префикс `AS_`. Тестовые обновления и отправка диагностики
в upstream выключены; BSD LICENSE и notices сохранены.

Внутренние сборки закреплены за `https://macmini.tailb71cbe.ts.net:10443`,
публичная конфигурация — за `https://aheadscale.ru:443`. Официальный процесс
сборки встраивает ограничение адреса: профиль другого окружения отклоняется без
перезаписи ключей, переноса регистрации или переключения аккаунта. MDM не может
перенаправить такой клиент в другое окружение.

Один desktop-пакет содержит службу и UI. Предусмотрены Linux amd64 desktop/CLI,
Linux arm64 CLI, Windows amd64/arm64 NSIS и macOS Intel/Apple Silicon pkg.
macOS включает отдельное удаление только Aheadscale; данные регистрации
сохраняются. Windows сохраняет данные, пока пользователь явно не выберет их
удаление. Целевые системы и необходимые библиотеки описаны в README клиента.

## Сборка и проверки

Версии Go, Node, pnpm, Wails и исходный commit закреплены в manifest; GitHub
Actions также закреплены по SHA. Workflow создаёт только временные CI artifacts.
Ключей подписания, загрузки на CDN и публикации releases в нём нет. Upstream
workflows сохранены в архивном каталоге и не исполняются в форке.

Локально прошли штатные тесты CLI, профилей, IPC/прав, packet marks и системных
маршрутов. Регрессионные тесты подтвердили прежнюю проблему и исправление для
настроенного сервера, конфликтующих marks, переменных другого продукта и
профиля другого окружения. Прошли ESLint без предупреждений, проверка ключей
переводов и actionlint. Штатный процесс собрал Linux arm64 CLI .deb; сборка не
устанавливает клиент на рабочем Mac mini.

Linux amd64 desktop/CLI .deb собраны штатным процессом в изолированной Ubuntu.
Прошли TypeScript/Vite, штатные тесты UI-служб и диагностики. Системный клиент
Windows amd64 и тест отдельного GUID адаптера скомпилированы; запуск на Windows
включён в CI. Подпись Git-коммитов выполняется GitHub через createCommitOnBranch,
настройки подписи Git и личные ключи владельца не изменяются.

Полный запуск Actions и проверка Windows/macOS ещё должны завершиться.
Наличие workflow не считается успешной сборкой.

## Условия внешнего запуска

В репозитории клиента `docs/aheadscale/acceptance.md` содержит отдельные шаги
проверки каталога устройств, offline, поиска/копирования IP и имени, системного
DNS, полезного SSH/HTTP, reboot/upgrade/uninstall и сохранности NetBird/Tailscale.
Результаты на чистых ОС пока Pending.

17 октября 2026 GET `/api/instance` приватного стенда вернул
`setup_required=false`: первичная настройка выполнена. Это не подтверждает
саморегистрацию пользователей, MFA, отдельную сеть каждого аккаунта,
серверный лимит пяти устройств или изоляцию каталога/DNS/трафика. Эти проверки
остаются обязательными, как и собственный подписанный канал обновлений, CDN,
Windows publisher certificate и Apple Developer ID/нотариализация.

До выполнения условий installers предназначены только для собственных испытаний.
