# Каталог загрузок Aheadscale

Экспортёр `packaging/aheadscale/downloads.py` подготавливает статический origin
для ручных загрузок. Он не проверяет наличие обновлений на устройстве,
не устанавливает пакеты и не разрешает выпуск беты.

## Подготовка preview

Исходный реестр — проверенный JSON в `headscale/docs/releases/`. Путь
`--artifact-root` ограничивает каталоги, из которых разрешено брать файлы.
Для кандидата Linux `.33`:

```bash
python3 -B packaging/aheadscale/downloads.py \
  --registry /home/adnako/Developer/headscale/docs/releases/2026-10-30-linux33-candidate.json \
  --artifact-root /home/adnako/VMs/aheadscale/release33 \
  --output /home/adnako/.local/share/aheadscale/downloads
```

Сначала проверяются версия, commit, архитектура, номер сборки Actions и точный
набор четырёх публичных GUI/CLI пакетов на архитектуру. Во время копирования
каждого файла проверяются размер и SHA256. Symlink и выход за разрешённый
каталог запрещены. Ошибка удаляет staging; частичная версия не публикуется.
Одновременный экспорт одной версии блокируется. После успеха существующая
версия не перезаписывается; изменения требуют новой версии.

Результат `preview/<version>/`:

- `manifest.json`: платформа, архитектура, вариант GUI/CLI, формат, размер,
  SHA256, commit, номер Actions и постоянный HTTPS-адрес каждого файла;
- `SHA256SUMS`: восемь проверяемых файлов с относительными путями;
- `linux-amd64/` и `linux-arm64/`: только выбранные публичные пакеты.

Публичные адреса начинаются с `https://aheadscale.ru/downloads/preview/`.
`public` в имени пакета означает адрес сервера, **не допуск к публичному выпуску**.
В preview всегда `releaseReady=false` и предупреждение о незавершённой приёмке.
Windows/macOS не добавляются этим экспортёром. Отдельный манифест беты
`/downloads/beta/manifest.json` остаётся пустым до решения Go/No-Go.

## Проверка происхождения и доставка

Исходный реестр должен быть взят из проверенного подписанного Git-коммита;
его нельзя заменять данными, полученными с неизвестного сайта. SHA256 выявляет
расхождение с этим реестром, но сам по себе не доказывает подлинность, если
злоумышленник одновременно изменил пакет и манифест. TLS и доверие к исходному
реестру необходимы; подписи установщиков остаются отдельным условием выпуска.

После загрузки файлов с сохранением относительных каталогов:

```bash
sha256sum --check SHA256SUMS
```

Origin получает каталог только для чтения и обслуживает GET/HEAD без листинга
директорий. У файлов нет истечения срока хранения GitHub Actions; CDN можно
подключить позже с сохранением относительных адресов. Копия на Mac mini
не является независимым резервным хранилищем.

## Целевые проверки

Workflow `Aheadscale download catalog` проверяет экспорт, отказ при изменении
байтов/размера/метаданных, безопасные пути и запрет перезаписи версии. На обычный
push этой ветки запускаются только он и быстрый CI-контракт. Это не полная
приёмка VPN и не сборка приложений.

Для независимой проверки доставки запустить этот же workflow вручную с
`delivery_smoke=true`. Runner скачает восемь пакетов без сохранения копий,
сверит их SHA256, размеры, закреплённый хеш манифеста и пустую бету, 404/405.
Обычный push не запускает сетевую доставку. Хеш манифеста `.33` закреплён
в workflow отдельно от проверяемого origin; при смене кандидата его обновляют
только после проверки нового экспорта.
