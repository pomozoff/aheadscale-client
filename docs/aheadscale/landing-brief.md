# Лендинг Aheadscale для первых пользователей

Черновик содержания и условий публикации. Лендинг представляет бесплатный
тестовый доступ для личных устройств и домашнего офиса. Основа оформления —
существующие логотип Aheadscale и синий цвет `#2563eb`, светлая и тёмная темы.
Это подготовка страницы; рабочие маршруты сайта пока не меняются.

## Первый экран

**Ваши устройства — в одной приватной сети**

Подключайте ноутбуки, рабочие компьютеры и серверы. Открывайте свои внутренние
сервисы по приватным именам и адресам из одной сети Aheadscale.

Основная кнопка: **Начать бесплатно**. Вторичная: **Как это работает**.

Под кнопками: **Бесплатный тестовый тариф — до 5 устройств.**

## Что можно делать

- **Доступ к своим компьютерам.** Подключайтесь по SSH и RDP к устройствам,
  на которых уже настроены соответствующие службы.
- **Работа с серверами разработки.** Открывайте внутренние веб-приложения,
  базы данных и инструменты команды через приватную сеть.
- **Понятные имена устройств.** Находите подключённые компьютеры в каталоге
  клиента и обращайтесь к ним по приватному имени.

## Три шага подключения

1. **Установите Aheadscale.** Выберите клиент для своего устройства.
2. **Войдите или создайте аккаунт.** При регистрации по email подтвердите
   адрес по ссылке из письма и задайте пароль.
3. **Подключите второе устройство.** Войдите в тот же аккаунт, найдите
   устройство в каталоге и откройте нужный сервис по приватному имени.

Адрес сервера уже задан в клиенте. Управление подключением доступно в приложении.

## Платформы и установщики

Текст для тестового периода: **Готовим приложения для Windows, macOS и Linux.
Первые версии проходят проверку на тестовом стенде.**

В опубликованной таблице загрузок должны быть конкретные ОС, архитектуры,
версии, контрольные суммы и ограничения именно выбранного выпуска.
Показывать активную кнопку загрузки только при наличии постоянной ссылки
на принятый установщик Aheadscale. Временные артефакты Actions для этого
не использовать.

Целевая матрица: Windows 11 x64/ARM64, Ubuntu и Fedora x64/ARM64, macOS ARM64,
Linux CLI x64/ARM64. Windows 10 требует отдельной приёмки; macOS Intel отложена.
Подпись Windows и Apple Developer ID/нотариализация macOS пока не готовы.
Список целевых платформ не означает готовность публичных установщиков.

## Условия первого доступа

Один аккаунт объединяет устройства одного владельца. В бесплатном тестовом
тарифе — до пяти устройств; ограничения должны соответствовать действующей
политике БД. Отдельные аккаунты сотрудников, приглашения и роли не обещать.

Сервис находится в тестировании. Публичный контакт поддержки, выбранный владельцем:
**support@aheadscale.ru**. До публикации адреса создать ящик и проверить входящие
письма и ответ пользователю. Postbox остаётся каналом отправки писем регистрации;
настройка входящей почты выполняется отдельно.

## Что подготовить перед публикацией

- Зафиксировать принятые пакеты и постоянные ссылки загрузки со своего CDN.
- Подтвердить матрицу платформ, подписи и ограничения выбранного выпуска.
- Показать реальный экран принятого клиента с демонстрационными именами
  устройств; личные аккаунты и данные владельца на лендинг не переносить.
- Проверить путь от кнопки до регистрации и установки. Сейчас `/peers`
  ведёт в существующий кабинет; для кнопки «Начать бесплатно» нужен
  согласованный путь без лишних возвратов между кабинетом и установщиком.
- Подключить support@aheadscale.ru, проверить входящую почту и ответ, подготовить
  необходимые документы для публичного доступа.
- Отдельно согласовать размещение страницы: корень `aheadscale.ru` сейчас
  обслуживает кабинет. Перенос кабинета или смена OAuth-адресов этим черновиком
  не разрешаются.

Не обещать отсутствие любых блокировок, универсальную правовую допустимость,
автоматические обновления через свой CDN или готовность всей матрицы ОС,
пока соответствующие проверки и выпуск не завершены.

## Бэклог поддержки

Позже создать официальные каналы поддержки Aheadscale в MAX и Telegram.
Перед подключением проверить доступные бизнес-функции, закрепить публичные
адреса, доступы владельца и порядок обработки обращений. Публиковать ссылки
после создания и проверки; отправку сообщений пользователям отдельно
согласовывать. Сейчас контакт лендинга — email.
