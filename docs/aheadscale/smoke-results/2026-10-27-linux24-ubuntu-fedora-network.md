# Linux `.24`: Fedora ARM64 ↔ Ubuntu ARM64

Дата: 27 октября 2026, время пользователя Asia/Krasnoyarsk. Продолжение [исправления NetworkManager](2026-10-26-linux24-networkmanager.md) по единому smoke-плану. **Сетевой smoke этой пары, управление через GUI Fedora и восстановление служб прошли. Полная релизная матрица остаётся открытой.**

## Стенд

| Узел | ОС / сеанс | Установленный комплект |
| --- | --- | --- |
| Ubuntu | Ubuntu 26.04.1 LTS ARM64, KDE/Wayland | Desktop DEB `.24`, kernel WireGuard `Aheadscale`, `100.88.19.208/16` |
| Fedora | Fedora 44 ARM64, GNOME/Wayland | Desktop RPM `.24`, kernel WireGuard `Aheadscale`, `100.88.185.206/16` |

Пакеты и исходник `c447fd6` не менялись: предыдущая сверка CI, SHA256 и обновления с сохранением ключей приведена в отчёте `.24`. Владелец завершил вход Fedora в прежний аккаунт. Обе ВМ синхронизированы по времени. Ubuntu использует bridged-сеть, Fedora — сеть UTM за MacBook; это один физический интернет-доступ, а не проверка разных операторов/NAT.

## Оснастка и границы

Использован штатный повторный запуск UI через механизм единственного экземпляра. `SIGUSR1` не отправлялся; после ранее найденного конфликта с JavaScriptCore это обязательное ограничение автоматизации. GUI Fedora продолжил работу; отладчик, специальные графические переменные и обходы защит не использовались.

Первая диагностическая проверка Fedora остановилась из-за отсутствия утилиты `wg`, хотя HTTP-сервис уже работал. Установлен только `wireguard-tools` (326 KiB), затем фактические порт и fwmark измерены и сохранены. Другие пакеты не обновлялись. Временные правила firewall не добавлялись: штатная зона FedoraWorkstation уже разрешала тестовый порт. Исходный отказ оснастки сохранён отдельно.

Открытие верхнего меню GNOME через AT-SPI оказалось недоступно; вместо этого проверена штатная страница Network → VPN. Кнопки Connect/Disconnect непосредственно в системных параметрах, визуальные уведомления во время отключения, полная тема/масштаб и все GUI-сценарии этим не принимаются.

Не выполнены: T03-OS/reboot, чистые CLI-пакеты и полный C01–C24, IPv6-прикладной обмен, разные внешние сети и принудительный Relay/возврат, изоляция аккаунтов, remove/reinstall и runtime x64. Скорость P01–P06 не измерялась по решению владельца. PASS этой пары не переносится на Windows/macOS или всю Linux-матрицу.
