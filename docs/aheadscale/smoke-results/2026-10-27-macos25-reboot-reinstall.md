Desktop `.24`. Серверная регистрация, политика входа, RG39 и защиты ОС

## T03-OS и автозапуск на исходном PKG `.25`

Штатная перезагрузка подтверждена изменением `kern.boottime`. FileVault
был выключен исходно; его состояние не меняли. До графического входа
владелец `/dev/console` — root, GUI отсутствует, служба автоматически Connected
с прежними ключом, VPN-IP и FQDN. Это daemon из Desktop-пакета,
а не приёмка чистой CLI/headless-установки.

Девять HTTP 200: macOS ↔ Ubuntu по VPN-IP, полному и короткому имени;
macOS → собственный IP/полное/короткое имя. Различаются маркеры обработчиков,
подтверждены исходный и удалённый VPN-IP. Временные слушатели удалены.
После обычного входа владельца GUI появился автоматически (PID 578),
без ручного запуска; Connected сохранился.

Первая автоматизация System Events получила timeout -1712 из-за ожидающего
запроса разрешения macOS. Владелец разрешил управление; меню Aheadscale
доступно и показывает Connected. Этот timeout не записывается как
зависание продукта. Первый снимок дал пустую рамку при активной заставке.
Наблюдавшийся `CGSSessionScreenIsLocked=1` сам по себе не доказывал,
что для возврата нужен пароль; владелец уточнил, что это заставка.

По прямому запросу владельца отключён её автоматический запуск только
в тестовой ВМ: пользовательский `com.apple.screensaver` / ByHost `idleTime=0`,
чтение подтвердило 0. Выполнено кратковременное штатное пробуждение;
параметры пароля и защиты входа не менялись. Тот же GUI PID 1923 стал доступен
через Accessibility. Новый снимок только окна Aheadscale подтверждает:
Connected, читаемый логотип Aheadscale в тёмной теме, прежний VPN-IP и
четыре устройства в каталоге; Ubuntu online. Ручной перезапуск GUI и службы
для этого не потребовался. Снимок сохранён в закрытых доказательствах как
`aheadscale-main-after-screensaver-pkg25-1.png`; дефект пустого UI не подтверждён.
Это визуальная проверка главного окна, а не весь UI-план.
Перезагрузка именно переупакованного `.25.1` этим результатом не закрывается.

## C13: обнаруженный FAIL и причина RG41

Штатный `Uninstall Aheadscale.command` завершился с кодом 0. Удалены своё
приложение, uninstaller, CLI-ссылка, launchd-служба/plist, GUI и квитанция
пакета. Собственного host route больше нет; физический default через en0
сохранён, публичный HTTPS отвечает 200. Без изменений сохранены SHA256:

- `/var/lib/aheadscale/default.json`;
- `/var/lib/aheadscale/active_profile.json`;
- `~/Library/Application Support/aheadscale/ui-preferences.json`.

Повторная установка исходного PKG `.25` завершилась с кодом 1: Installer
обновил оставшуюся от прежней проверки копию `PreviousAheadscale.app`
в `~/Library/Logs/AheadscaleSmoke/upgrade22.NHNI0M/`, а postinstall ожидал
`/Applications/Aheadscale.app`. Причина подтверждена `install.log` и
штатной документацией `pkgbuild`: переносимость bundle определяется
метаданными компонента, а значения по умолчанию зависят от версии сборщика.
Данные аккаунта не потеряны. Это дефект упаковки, даже если провоцирующая
копия возникла в тестах: существующий контракт скриптов требует канонический путь.

## Исправление и повтор на PKG `.25.1`

Настоящий упаковщик сначала выполняет `pkgbuild --analyze`, требует ровно
один компонент `Applications/Aheadscale.app`, явно задаёт
`BundleIsRelocatable=false` и передаёт `--component-plist` в `pkgbuild`.
Остальные свойства компонента сохраняются. Две Python-регрессии выполняют
реальный `package.py` с подменой только платформенных утилит: старый анализатор
возвращает true, новый опускает default false. Зафиксирован RED → GREEN;
обе проверки прошли на Linux и macOS и добавлены в CI.

Повтор выполнен настоящим Installer при сохранённой дублирующей копии:

| Проверка | Результат |
| --- | --- |
| Штатное удаление | Код 0; перечисленные собственные ресурсы отсутствуют, обычная сеть работает |
| Сохранение трёх файлов настроек | Все SHA256 совпали до удаления, после удаления и после установки |
| Установка `.25.1` | Код 0, приложение в `/Applications/Aheadscale.app` |
| Восстановление | Connected без SSO; прежние ключ, VPN-IP, FQDN и число соседей |
| GUI | Процесс запущен; меню показывает Connected |
| Дублирующая тестовая копия | Полный `diff -qr` с исходным CI bundle — без различий, код 0 |
| Прикладная сеть | Ещё 9/9 HTTP 200: обе стороны по IP/именам и собственный адрес macOS |
| Оснастка | Оба временных HTTP-слушателя удалены |

Всего в этом отчёте **18 новых успешных HTTP-проверок**; 36 из предыдущего
RG40 не пересчитываются как новые. Рабочее приложение/служба не запускаются
из временного каталога. После сохранения доказательств ненужные исходники,
пакеты-прототипы и собственная старая тестовая копия удалены. Служба и GUI
продолжают работать из `/Applications`, VPN остался Connected.
