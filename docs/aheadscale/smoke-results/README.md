Порядок работы — [единый тест-план](../smoke-test-plan.md). Исторический отчёт подтверждает только свой пакет/стенд, а не полный PASS текущего кандидата.

Новые результаты оформлять по шаблону общего плана с SHA256, commit и версиями всех компонентов. Миграция отчёта не означает интеграцию его незавершённых исходников в main.

Для повтора Windows x64 использовать [стенд на Mac mini](../windows11-x64-lab.md). Первый прогон Aheadscale зафиксирован 24 октября; чистый снимок до установки сохранён отдельно от зарегистрированной ВМ.
