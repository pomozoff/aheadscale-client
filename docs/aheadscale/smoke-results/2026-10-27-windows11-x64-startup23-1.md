# Windows x64: автозапуск и сохранение выбора, упаковка `.23.1`

27 октября 2026 года. Windows 11 x64, фактическая версия ОС `10.0.26300.9711`. Целевая проверка после [уточнения `.23`](2026-10-27-limit6-windows-followup.md).
Исследование задержек отложено; загрузка ОС/RDP и время ввода не измерялись как VPN.

## Воспроизведение и исправление RG22

На прежнем `.23` установка поверх сохранила Run, следующий реальный reboot
запустил GUI и VPN автоматически: это не потеря настройки. Настоящий полный
remove/reinstall дал другой результат: до удаления задача включена; после
удаления и повторной установки нет ни задачи, ни Run/StartupApproved.
Три файла default/active profile/UI preferences побайтово сохранены.
При следующем фактическом входе GUI отсутствует, native VPN Disconnected,
CLI Idle. Пустой ключ в Idle-ответе не означает удаления ключа из конфигурации.

Причина: удаление правильно очищает системные записи, но выбор пользователя
отдельно не сохранялся, а существующий marker `autostartInitialized` запрещает
повторно применять начальный default при переустановке.

Общий helper теперь при remove сохраняет только проверенный пользовательский
DWORD `HKCU\Software\Aheadscale\DesktopInstallerStartupV1:Enabled`.
Новая операция restore применяется установщиком после размещения native UI.
Без сохранённого выбора начальное поведение не меняется; false остаётся false.
Это пользовательская настройка, сохраняемая вместе с прежними конфигурациями;
при удалении нет работающей задачи/Run. Изменённые чужие задачи/Run не трогаются,
неправильный тип или значение флага отклоняются. Повышения прав задачи нет.

Два параметра проверяются раздельно: Launch UI at Login управляет GUI,
Connect on Startup — соединением. Новая загрузка подтверждается LastBootUpTime:
первая попытка disabled reboot не выполнилась и оставила прежнюю загрузку;
она сохранена отдельно и не засчитана как T03-OS. Проблемы фокуса ввода и
RDP-папки относились к оснастке; ни SSH-отказ, ни отсутствие файла не считались
отрицательным результатом VPN. Ручные подготовительные запуски GUI явно
отделены от проверки автозапуска.
