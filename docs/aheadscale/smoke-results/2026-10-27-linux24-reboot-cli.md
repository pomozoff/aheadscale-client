## RG37: замена вариантов RPM — FAIL

В одной DNF-транзакции устанавливается aheadscale-cli и удаляется aheadscale (при возврате наоборот). Новый `%post` включает службу, затем `%preun` старого пакета останавливает и отключает тот же `aheadscale.service`. Оба раза DNF завершился с 0, а служба осталась inactive/disabled. Порядок скриптов и удаление enable-symlink сохранены в журнале. Регистрация не потеряна.

Ручное восстановление использовано только для продолжения тестов и возврата рабочего стенда. Оно **не исправляет установщик и не закрывает C01/C13**. Новая регрессия: Desktop → CLI → Desktop одной транзакцией для каждой смены, без ручного запуска; прежний узел, активная/включённая служба и T01 после каждой. Обычное обновление того же варианта и окончательное удаление проверить отдельно, включая очистку только своей сети. Исходники упаковщика этим прогоном не исправлялись.

## Сеть: 42 принятых HTTP-запроса

Семь полных серий T01 по шесть запросов: после включения Ubuntu; после reboot Fedora до графического входа; после CLI up Ubuntu; после CLI service start Ubuntu; после CLI up Fedora; после CLI service start Fedora; после возврата обоих Desktop. В каждой — VPN IPv4/FQDN/короткое имя в обе стороны, HTTP 200, точный маркер получателя, фактические VPN-адреса отправителя и `remote_ip`, HTTP-прокси исключён. IPv6 HTTP, другие операторы/NAT и Relay этим не принимаются.

Один исходный T01 после CLI up Ubuntu не прошёл из-за завершившегося HTTP-fixture Fedora: без графического сеанса пользовательский systemd-manager завершился после выхода SSH, слушателя уже не было. Временный сервис переведён в ограниченный по времени системный unit от имени adnako; после локальной проверки сервиса полная серия повторена. Ошибка оснастки не зачтена как PASS и сохранена отдельно.

Другие исправления наблюдателя: YAML datetime корректно сериализован при сборе; GUI Fedora найден по фактическому executable `/proc`, поскольку gnome-session меняет argv. Первый поиск по argv и раннее чтение ещё не загруженного AT-SPI-дерева не дали результата; позднее подтверждены автозапущенный процесс и checked toggle. Новых core после reboot нет; эти ошибки не объявлены падениями приложения.
