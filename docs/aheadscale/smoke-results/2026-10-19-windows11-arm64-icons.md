# Значки Windows 11 ARM64: проверка сборки `.8`

Дата: 2026-10-19. Продолжение [парного прогона Windows и Ubuntu](2026-10-19-windows11-arm64-ubuntu26-connectivity.md).

## Результат

На тестовую Windows VM установлен новый пакет `.8`. В панели задач и заголовке
главного окна виден синий значок Aheadscale с буквой A. Ярлыки рабочего стола
и меню «Пуск» ссылаются на существующий `.exe` и явно используют его значок.
Вход повторять не потребовалось: открытый ключ устройства, VPN IP и FQDN
сохранились, служба и окно показывают подключение.

## Причина и исправление

В установленном GUI `.3` отсутствовал раздел Windows-ресурсов. Штатный
`ExtractIconEx` возвращал ноль групп значков. Сценарий Aheadscale вызывал
`go build`, пропуская имеющийся в Wails шаг генерации `.syso`. Значок установщика
при этом присутствовал, поэтому его наличие не доказывало правильность GUI.

В сценарий сборки добавлена генерация ресурса для целевой архитектуры через
закреплённый `wails3 generate syso`, до сборки GUI. В ресурс включается собственный
многоразмерный ICO Aheadscale. Временный `.syso` удаляется и после успеха, и при
ошибке. Обновлены исходные Windows-метаданные и манифест. Уровень запуска
`asInvoker` сохранён, новые зависимости приложения не добавлялись.

В установщике исправлены `DisplayIcon` и оба ярлыка: используются полный путь
к `aheadscale-ui.exe` и индекс значка 0. Исходники NetBird NSIS напрямую не
переписывались: преобразование выполняется упаковщиком Aheadscale.

## Проверки

| Проверка | До | После |
| --- | --- | --- |
| `ExtractIconEx` установленного GUI | 0, ошибка проверки | 1, код проверки 0 |
| Раздел ресурсов GUI | Отсутствовал | Присутствует, ARM64 |
| Панель задач | Общий значок программы | Собственный синий значок Aheadscale, проверен снимком экрана |
| Заголовок главного окна | Не использован как достаточное доказательство | Значок Aheadscale и заголовок Aheadscale |
| Ярлыки рабочего стола и меню «Пуск» | Цель без расширения, источник значка не задан | Существующий `aheadscale-ui.exe`, `IconLocation=...Aheadscale-ui.exe,0` |
| Значок в записи удаления Windows | Указывал на CLI без расширения | Указывает на GUI `.exe,0` |
| Установка поверх `.3` | — | Код установщика 0, версия CLI `.8`, служба Running/Connected |
| Регистрация после обновления | — | Открытый ключ, VPN IP и FQDN сохранены, повторный вход не нужен |

Использованы `bash -n` для сценария сборки, `python3 -m py_compile` для упаковщика,
`git diff --check`, реальная сборка ARM64-установщика, установка и штатные API
Windows. Новый тестовый фреймворк не добавлялся.

Поля файловой версии через `.NET FileVersionInfo` в этой VM вернулись пустыми,
хотя исходные строки Aheadscale включены в ресурс. Отображение этих свойств не
подтверждено и не засчитывается как PASS; значки проверялись отдельно.
