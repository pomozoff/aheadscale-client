Полный UI-прогон не выполнен. Снимки Fedora x64 показывают браузерный вход,
но не доказывают проверку всех элементов клиентского окна. Обычная SSH-сессия
требует дополнительной авторизации NM и не подменяет активный desktop-сеанс.
Системные кнопки GNOME/Plasma и все Connect/Disconnect/Cancel ещё должны пройти
отдельную проверку на обеих ОС.

## Что осталось

Перезапуски контроллера/демона/плагина при ON/OFF, аварийное завершение и поздний
Up, Desktop boot и autostart OFF, remove/reinstall и переходы Desktop ↔ CLI
на новых ARM-пакетах. Затем Ubuntu Desktop x64, полный Fedora x64 и CLI ARM64.
Internal runtime не проверен. RG39 и поиск задержек не изменялись.

Для Fedora x64 отправлен вопрос готовности подтвердить свежий код входа;
доступ ARM зависит от MacBook. HTTP-службы имеют TTL 30 минут. Firewall-правило
Fedora ограничено источником CLI VPN `/32`, TCP 8765 и тем же TTL. Точные пути
уборки сохранены приватно в `release29/evidence/t01-31p2/*-cleanup.json`.

Исходники сохранены подписанными коммитами в рабочих ветках. Перенос функции
в main, заключительная самопроверка одним агентом и полная приёмка не завершены.
