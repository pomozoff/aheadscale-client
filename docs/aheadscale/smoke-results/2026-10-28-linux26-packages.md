# Приёмка Linux-пакетов .26

Продолжение [плана Linux-поставки](../release-candidate-worklist.md) после
[исправления RG42](2026-10-28-rg42-networkmanager-disconnect.md).
Статус: подготовка сборки; пакеты и перечисленные ниже сценарии ещё не приняты.

## Согласованный комплект

Исходная реализация: `b56c196`. Нужны Desktop и CLI, DEB и RPM, для amd64 и
arm64 из одного исходного состояния с Go 1.26.7 и зафиксированными Node/pnpm.
Используется существующий preview CI; установщики без публичной подписи,
предназначены для испытаний. Публикация релиза/CDN в этот этап не входит.

Подготовительный коммит помечен `[skip ci]`, чтобы отправка рабочей ветки
не запускала общую матрицу. Два явных запуска workflow_dispatch выбирают
`linux-amd64` и `linux-arm64`, включая существующие тесты и проверки упаковки.

## Последовательность приёмки

1. Дождаться успешных CI-проверок/сборок; скачать артефакты и сверить
   sourceCommit, версии, архитектуры и SHA256 всех пакетов.
2. На Fedora x64 и Ubuntu CLI x64 проверить обновление из нового RPM/DEB,
   версии GUI/демона, регистрацию, конфигурации и реальные HTTP/DNS.
3. На Ubuntu Desktop ARM64 и Fedora ARM64 проверить обновление пакетом,
   реальное системное отключение, согласованность GUI/CLI и отсутствие
   самоподключения; вернуть Connect без повторного входа.
4. Проверить обычные GUI/CLI Down/Up, перезапуск службы и трафик между узлами.
   Ранее принятые lifecycle/RPM-переходы сохраняют привязку к своим версиям;
   необходимый повтор описать с фактически проверенной областью.
5. Обновить матрицы/план, сохранить отчёт подписанным коммитом в main,
   убрать собственные временные файлы, процессы и рабочие копии.

## Ограничения

Полный R05 (системный Connect/Cancel), перезапуск самого NetworkManager,
полные UI/CLI, другие платформы и публичные подписи этим списком не закрыты.
RG38 остаётся отдельной задачей; RG39 по решению пользователя не исправляется.
