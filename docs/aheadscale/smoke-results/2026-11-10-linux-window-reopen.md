# AHEAD-68: повторное открытие Linux GUI

## Изменение

Для Linux удалён собственный обработчик SIGUSR1: отдельная platform-specific
реализация не регистрирует, не игнорирует и не блокирует сигнал WebKit.
Повторный запуск, launcher и tray используют прежний SingleInstance/ShowWindow.
macOS сохраняет Unix-обработчик; Windows — прежний named event.
Авторизация, D-Bus, NetworkManager и графические зависимости не менялись.

Это удаление конфликтующей команды из интерфейса Aheadscale, а не обещание
безопасности произвольного внешнего `kill -USR1` для JavaScriptCore.

## Нативная проверка: ещё не выполнена

Существующая Kubuntu доступна на loopback SSH 12237, её сохранённый host key
проверен; штатный агентский ключ не принят. Установленный пакет не заменялся.
Второй экземпляр QEMU не запущен: исходный процесс уже работает и PID-lock
отклонил повторный запуск.

Автоматическая проверка отклонила попытку использовать ключ из каталога другого
стенда без подтверждённого назначения. Запрошено отдельное разрешение владельца;
повторной попытки с этим ключом до разрешения нет.

После восстановления доступа: сохранить прежний UI, установить проверочный
бинарник с сохранением владельца/прав, запустить в обычной пользовательской
графической сессии; несколько раз скрыть/открыть через launcher/tray. Проверить
один основной PID, видимость окна, отсутствие нового core и сохранение состояния
VPN/ключа. Только после этого закрывать AHEAD-68.

Автор выполнил self-review одним агентом по требованию владельца.
Независимого ревью и свежего установленного native PASS пока нет.
