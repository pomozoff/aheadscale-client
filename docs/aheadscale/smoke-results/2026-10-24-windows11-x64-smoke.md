### Воспроизведение падения GUI

Запуск установленного `aheadscale-ui.exe` обычным пользователем через
ярлык и напрямую завершает процесс с кодом **1**, без видимой ошибки.
При прямом запуске код получен через `System.Diagnostics.Process`;
stdout/stderr пусты, журнал содержит начало настройки значка трея.
В одном запуске журнал успел получить состояние NeedsLogin от службы.

Два независимых диагностических варианта также завершились с кодом 1:
отключение GPU только для процесса WebView2 и отдельный новый каталог
данных WebView2. Изменения окружения не сохранялись в системе.
Причина падения **не установлена**; наличие WebView2 и этих повторов
недостаточно, чтобы обвинить драйвер, антивирус или конкретный компонент.
Отсутствующая корректная иконка — отдельный подтверждённый дефект.

ручные DNS-серверы не менялись; использован системный резолвер Windows.

## Очистка и воспроизводимость

В отчёте сохранены точный пакет, SHA256, исходник, результаты каждого
направления и первые отказы. Полные операторские журналы, OAuth code/state,
пароли и ключи не включены в репозиторий. Временные правила firewall для
HTTP не потребовались, глобальные защиты не отключались. Новые аккаунты и
дубликаты устройства не создавались.

Временный SSH-ключ с ограничением источника на VPN IP A удалён из Ubuntu,
его файлы удалены из Windows. Оба HTTP-ответчика остановлены, TCP 8765
в Windows больше не слушается; временные файлы Ubuntu и проброс RDP через B
удалены. Итог: Windows Connected, обычный HTTPS = 200.
Диагностический ZIP из системной папки Windows удалён с UAC. Служба,
регистрация и штатный RDP-доступ оставлены для дальнейшей работы.
