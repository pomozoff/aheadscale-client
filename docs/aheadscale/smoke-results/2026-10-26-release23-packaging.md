Ответ пользователя не получен в пределах пятиминутной попытки; затем callback закрылся. Первоначальное наблюдение закрытого порта сделано после истечения попытки и не доказывает отказ службы. Неточное сообщение GUI про неответившую службу требует отдельного воспроизведения ошибки SSO. Авторизация, подключение и T01 на `.23` пока NOT_RUN; таймауты/проверки авторизации не ослаблялись.

На Windows ARM отдельно прошла безопасная часть C01/C02/C05/C12: version, --help, up/status/service --help и service status вернули 0; неизвестная команда — 1 с сообщением; JSON и YAML разобраны стандартными парсерами. Состояние NeedsLogin указано явно. Это не чистая CLI-установка и не полный PASS этих сценариев.

Первый ARM-наблюдатель истёк до готовности своего отчёта; последующая проверка прочитала успешный результат установщика. На x64 первая RDP-команда не скопировала результат в общий каталог; повтор прочитал уже существующий локальный результат без повторной установки. Ошибки оснастки сохранены и не названы дефектами приложения.

В момент проверки ни один сосед ещё не был Connected; фактический обмен этим обновлением не доказан. Закрытая копия для отката находится в `/root/aheadscale-smoke-release23-20261026/` внутри Ubuntu.

## Linux и общий CI

Восстановлены `rpm_package.py`, RPM spec и vendor unit из сохранённого SDK-проекта 21 октября. Desktop RPM содержит GUI и службу; отдельный `aheadscale-cli` не зависит от GTK/WebKit. Пакеты взаимно исключают установку; конфигурация сохраняется. Неизвестный локальный unit останавливает установку до перезаписи.

Сборочная Fedora зафиксирована OCI digest; версии RPM-инструментов зафиксированы. Упаковка выполняется без сети, capabilities и доступа к исходникам/секретам в контейнере, от обычного UID, с узкими mount только собственных артефактов. Она не заменяет Fedora runtime smoke.

Проверка на синтетическом ELF дала RED до восстановления `--format rpm`, затем GREEN для настоящего формата RPM, заголовков, состава и зависимостей desktop/CLI. Синтетические пакеты не распространяются. Реальный [CI 40321330374](https://github.com/pomozoff/aheadscale-client/actions/runs/40321330374) из `0cc48b3` собрал восемь ARM64-пакетов: DEB/RPM × desktop/CLI × internal/public; версии и архитектуры заголовков повторно проверены. Linux CI также установил internal DEB, запустил службу, выполнил status и удалил пакет.

У этого первого CI SHA256SUMS оказался сформирован до RPM. Исправление `b52f181` формирует его после всех пакетов и сохраняет JSON-манифест с исходным коммитом, версией, платформой, архитектурой, именами, размерами и SHA256. Финальные сборки: Linux ARM64 [40323591453](https://github.com/pomozoff/aheadscale-client/actions/runs/40323591453), общий комплект [40323589714](https://github.com/pomozoff/aheadscale-client/actions/runs/40323589714). Оба CI завершились успешно. Скачаны 8 Linux x64, 8 Linux ARM64 и 2 macOS пакета; у каждого совпали commit, версия, размер и SHA256 из манифеста и SHA256SUMS. В общем CI первый Windows job был остановлен на длительной подготовке системных пакетов; точечный повтор на другом runner прошёл. Результаты Linux/macOS сохранены без повторной сборки.

## Регрессии и оставшаяся работа

Семь реальных NSIS/7z проверок прошли: корректные x64/ARM64 EXE и отказ смешанных commit, версий, стандартного PE, native UI PE и MSIX. Python/shell/workflow syntax, `git diff --check` и обязательный `make lint` прошли для изменений упаковки. Общий [CI 40310075576](https://github.com/pomozoff/aheadscale-client/actions/runs/40310075576) также прошёл unit/identity и сборки Linux x64, Windows x64, macOS ARM64 из `f9a52d8`.

Не закрыты: чистые установки, полный UI/CLI, шесть направлений HTTP/DNS T01, reboot/remove/reinstall `.23`, отдельный headless CLI, разные NAT/Relay, изоляция аккаунтов и серверные условия допуска. Windows 10, Linux x64 runtime и нижняя граница macOS не приняты. Системный VPN macOS требует отдельного Network Extension и Apple Developer Program. Задержки подключения по решению владельца не исследовались.

Сводный [манифест 13 пакетов с публичным адресом сервера](/home/adnako/VMs/aheadscale/release23/smoke-20261026/candidate-manifest.json) включает происхождение, SHA256, размеры, зафиксированные в CI версии инструментов, хеши dependency lock-файлов и границы приёмки каждого варианта. Windows — `f9a52d8`, Linux/macOS — `b52f181`; между точками изменены упаковка/CI и документация, код сетевого движка не менялся. Preview EXE/DEB/RPM/PKG с публичным адресом не означают публичный релиз.

Приватные свидетельства и точные пакеты сохраняются в `/home/adnako/VMs/aheadscale/release23/smoke-20261026/`; исходные личные данные и секреты в Git не помещаются.
