# Чистый Ubuntu Server x64: отдельный CLI `.24`

27 октября 2026 года. Это проверка установки и локального жизненного цикла
без Desktop, а не приёмка зарегистрированной VPN-сети.

## Стенд и пакет

- Ubuntu Server 24.04.5 LTS, x86_64, KVM, 2 vCPU / 2 ГиБ RAM; нет GUI,
  NetworkManager, GTK/WebKit из desktop-установщика.
- [Официальный образ Canonical](https://cloud-images.ubuntu.com/noble/current/)
  `noble-server-cloudimg-amd64.img`, daily 20261017, SHA256
  `04e8f2461a16a44e78a370284471f29616cdd9baf1893df25807b71f985b6c94`.
  SHA256 сверён с официальным HTTPS-манифестом; отдельная GPG-подпись образа
  этим прогоном не проверялась.
- Первичная настройка через [NoCloud CIDATA](https://docs.cloud-init.io/en/latest/reference/datasources/nocloud.html),
  SSH только по существующему публичному ключу. Гостевой ED25519 сверён
  с доверенной QEMU-консолью; парольный вход не включался.
- `aheadscale_0.80.0-aheadscale.24_linux_amd64_public_cli.deb`, SHA256
  `904c6064c7cf5d52f6205603b6d28af6bb9885e2d51916f3df3c2b01187939aa`,
  сверён с исходным `SHA256SUMS`. Имя DEB-пакета — `aheadscale`, не
  `aheadscale-cli`; вариант CLI определяется артефактом.

## Результаты

| Проверка | Результат |
| --- | --- |
| C01: чистая установка | PASS для установки: apt exit 0; версия `.24`; служба enabled/active, GUI/NM не установлены |
| C05 и справка | Частично PASS: 29 ограниченных по времени команд без зависаний; JSON и YAML разбираются и показывают NeedsLogin. Пустые адреса до регистрации ожидаемы, сетевой каталог не принят |
| C10 / часть C12 | Три неверных аргумента отклонены; health-check записаны отдельно для исходного NeedsLogin и остановленной службы; состояние после штатного запуска active |
| C02 с правами | sudo stop/start/status работают, после start служба active. Без прав start даёт 1 и только `Error: start service: exit status 1`: RG38 воспроизведён, понятное объяснение пользователю ещё требуется |
| C12: отмена входа | `up --no-browser` ожидал завершения; SIGINT завершил попытку, после выдержки нет локального слушателя 53000 или позднего Connected. Временный закрытый вывод удалён. Это не доказательство завершения входа с другого устройства |
| C13 до регистрации | Настоящее apt remove убрало unit (`LoadState=not-found`, inactive) и бинарник. Оба существующих файла default/active profile сохранили SHA256; тот же DEB установлен заново, версия верна, служба active |
| Перезагрузка без GUI | Новый boot ID, unit enabled/active, ожидаемый NeedsLogin. Это запуск службы до графического входа, не C09 PASS восстановления зарегистрированного туннеля |

Первый оператор удаления ошибочно использовал имя `aheadscale-cli`;
переустановка поверх существующего пакета не была засчитана. После чтения
DEB-метаданных выполнено настоящее удаление с обязательной проверкой
отсутствия unit/бинарника до установки. Это ошибка оснастки, не пакета.

Открыты C03 с завершённым удалённым входом, C04/setup key, C06–C09 с реальным
соседом и сохранением зарегистрированного устройства, C11, дополнительные
команды/настройки и полный C01–C24. Существующие пять пользовательских устройств
не удалялись для освобождения места; отдельный тестовый аккаунт/допустимый узел
ещё не подготовлен. Desktop x64 и Fedora x64 этим прогоном не закрываются.
