# Windows 11 x64: один браузерный вход, 25 октября 2026

Это проверка закрытых preview `.13` и `.14`, не общий стабильный релиз.

## Причина и исправление

В `.12` посредник системного VPN запускал `aheadscale up`, который сам открывал браузер и ожидал PKCE. UI реагировал на NeedsLogin своим Login/WaitSSO. Журнал ВМ подтвердил начало первого ожидания, его отмену, второе ожидание и успешный обмен кода на токен; системный Connect при этом завершился ошибкой. Повторный Connect `.12` без новой авторизации поднял VPN: прежний SSO сохранил регистрацию, а не полностью провалился.

Посредник теперь использует существующий `up --no-browser`. Перед GUI Login общий контроллер дожидается отмены и cleanup прежней native-попытки; ошибка cleanup не разрешает начать новый Login. Это же намерение блокирует запоздалый автоматический Resume. Обычный Login без native backend не изменён. Проверки PKCE/state, владельца и подписей не отключались.

## Повтор после разрешённого Logout: `.14`

Пользователь разрешил Logout только Windows-ВМ. Команда завершилась exit 0, текущая серверная запись удалена, системный VPN отключился; Ubuntu осталась Connected. В `.13` первая PKCE-попытка посредника отменена при передаче управления UI; новый GUI WaitSSO начался в 10:27:29 (+03:00), но отменён в 10:27:42 после завершения старого broker. Его метки показывают timeout открытия канала и завершающий Disconnect. Это отдельная RG24: одна вкладка ещё не означает успешный вход.

Исправление `.14`: после внешнего RAS Disconnect ждать освобождения уже существующего mutex native-посредника текущего SID, который удерживается до конца его Down. Ожидание ограничено 30 секундами и контекстом; Windows mutex захватывается и освобождается на одном OS-потоке. Брошенный mutex и ошибка доступа не считаются подтверждением cleanup. Новый Login идёт только после этой границы и дополнительного Down.

На настоящей Windows два новых теста сначала упали: Login обгонял занятый mutex, отмена ожидания возвращала nil. После исправления все три проверки cleanup и предыдущие native Login/Connection прошли с `-race`, exit 0. Общие `make test-unit` и host race прошли. Линтеры Linux и Windows: 0 issues.
