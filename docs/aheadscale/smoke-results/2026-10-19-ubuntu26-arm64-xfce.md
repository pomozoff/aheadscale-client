# Smoke: Ubuntu 26.04.1 LTS ARM64, Xfce

Дата: 2026-10-19. План: [smoke-проверки Linux](../smoke-test-plan.md).

## Итог

Локальный цикл подключения в Xfce пройден. Системный VPN-апплет показывает
Aheadscale и обновляет состояние после отключения и подключения.
Полный smoke заблокирован отсутствием второго устройства. Два найденных дефекта
оформления закрыты повторной проверкой сборки `.7`; результаты первого прогона
на `.6` сохранены ниже.

## Стенд

- Та же Ubuntu 26.04.1 LTS ARM64, дополнительный сеанс Xfce X11.
- Ядро `7.0.0-38-generic`, xfce4-session 4.20.4, NetworkManager 1.54.3.
- Использован nm-applet; экран входа GDM сохранён.
- Пакет `0.80.0~aheadscale.6`, GUI `.3`, служба `.6`.
- Базовый commit `dfa0924f52fc8f516863bf2f50a2782f94da377a` и локальные изменения;
  артефакт и SHA256 — в [отчёте сборки](../preview-report.md).
- Регистрация перенесена с предыдущего сеанса этой VM. В каталоге нет второго
  устройства. Чистая установка Xubuntu этим прогоном не проверялась.

## Дефекты оформления

- **UI-01, FAIL:** надпись Aheadscale над переключателем почти не видна на тёмном
  фоне. То же наблюдение есть в [отчёте KDE](2026-10-19-ubuntu26-arm64-kde.md).
- **UI-03, FAIL:** в левом углу заголовка окна видна обрезанная синяя часть значка.
  В панели задач и системном трее значок отображается правильно. Повторение:
  открыть главное окно в Xfce X11 и сравнить значок заголовка со значком панели.

## Автоблокировка тестовой VM

По запросу владельца отключено автоматическое блокирование экрана во всех трёх
установленных окружениях; значения прочитаны обратно после сохранения:

| Окружение | Сохранённая настройка |
| --- | --- |
| KDE | `Daemon/Autolock=false`, `Daemon/LockOnResume=false` в `kscreenlockerrc`. |
| GNOME | `org.gnome.desktop.screensaver lock-enabled=false`, `org.gnome.desktop.session idle-delay=0`. |
| Xfce | `/saver/idle-activation/enabled=false`, `/lock/saver-activation/enabled=false`, `/lock/sleep-activation=false` в канале `xfce4-screensaver`. |

Это настройка операторского стенда. Установщики и исходники клиента для этого
не изменялись. Имена свойств Xfce сверены с
[исходниками xfce4-screensaver](https://raw.githubusercontent.com/xfce-mirror/xfce4-screensaver/master/src/gs-prefs.h).

## Что не проверено

S01/S02 и поля браузерной формы S03 — NOT_RUN. S05/S06 и обращения ко второму
устройству из S07/S08 — BLOCKED. R01 целиком, R02–R08 и принудительный Relay —
NOT_RUN. Перезапуск GUI не засчитывается за перезагрузку ОС.
Пункт Aheadscale в системном VPN-меню не переключался: проверено его отображение
и обновление состояния вслед за переключателем самого клиента.

## Повторная проверка оформления: сборка `.7`

В ту же VM установлен пакет `0.80.0~aheadscale.7`: служба и GUI версии `.7`.
Установщик и его SHA256 указаны в [отчёте сборки](../preview-report.md).

| Проверка | Результат | Наблюдение |
| --- | --- | --- |
| UI-01: главное окно, тёмная тема | PASS | Название Aheadscale белое и читается на тёмном фоне. |
| UI-01: главное окно, светлая тема | PASS | Название тёмное и читается на светлом фоне. |
| Экран «О программе», обе темы | PASS | Логотип и название читаются на светлом и тёмном фоне; GUI и служба показывают `.7`. |
| UI-03: значок главного окна | PASS | В заголовке отображается целый значок Aheadscale. Проверено после запуска установленного GUI без ручной подмены значка. |
| UI-03: значок окна настроек | PASS | Значок целиком виден и в дополнительном окне. |
| Передача значка оконному менеджеру | PASS | Реальное окно содержит `_NET_WM_ICON`, которое отсутствовало до исправления. |
| Состояние после обновления | PASS | Клиент остаётся Connected; повторный вход не потребовался. |

Причина UI-01 — перепутанные цвета текста в двух SVG для светлой и тёмной тем.
Причина UI-03 — GTK4-версия оконной библиотеки не передавала значок поверхности
оконному менеджеру X11. Клиент передаёт встроенный PNG через GdkToplevel при
загрузке окна и получении фокуса. Изменять настройки Xfce пользователю не нужно.

Доказательства на VM: `ui-fix-xfce-dark-7.png`, `ui-fix-xfce-light-7.png`,
`ui-fix-xfce-settings-7.png`, `ui-fix-xfce-about-light-7.png`,
`ui-fix-xfce-about-dark-7.png` в прежнем закрытом
операторском каталоге. Копия текущей проверки: `/tmp/aheadscale-ui-fix`.
Эта проверка оформления не заменяет невыполненные сетевые сценарии выше.

Исходный выбор темы `System` восстановлен после проверки. Сверены SHA256
установщика на машине сборки и в VM, а также установленного GUI.
