# Отправка писем регистрации Aheadscale

Провайдер для начала — Yandex Cloud Postbox, отправитель —
`Aheadscale <noreply@aheadscale.ru>`. Это предложенная конфигурация:
реальный аккаунт, DNS и отправка ещё не настроены.

## Что подготовить в кабинете

1. В [Yandex Cloud](https://console.yandex.cloud/) создать или выбрать облако,
   каталог для Aheadscale и подключить платёжный аккаунт по условиям сервиса.
   Создание платных ресурсов и пополнение выполняет владелец.
2. В Cloud Postbox создать адрес для домена `aheadscale.ru` с простой настройкой
   DKIM. Скопировать выданные сервисом DNS-записи в панель landvps.ru.
   Значения DKIM берутся именно из кабинета; примерными ключами их не заменять.
3. Дождаться подтверждения домена. SPF и DMARC добавить по
   [инструкции DNS](https://yandex.cloud/ru/docs/postbox/concepts/dns-records).
   Если SPF уже есть, дополнить существующую запись, не создавать вторую.
   Существующие MX, A/AAAA и записи других отправителей сохраняются.
4. В том же каталоге создать сервисный аккаунт `aheadscale-mailer` с ролью
   `postbox.sender` и API-ключом с областью `yc.postbox.send`.
   Идентификатор и секрет сохранить локально в менеджере секретов.

Параметры сервера после реализации SMTP-отправителя:

| Параметр | Значение |
| --- | --- |
| SMTP-сервер | `postbox.cloud.yandex.net` |
| Порт | `587` |
| Шифрование | обязательный STARTTLS с проверкой сертификата |
| Имя пользователя | идентификатор API-ключа |
| Пароль | секретная часть API-ключа |
| Отправитель | `Aheadscale <noreply@aheadscale.ru>` |

Не путать API-ключ со статическим ключом доступа: для последнего провайдер
требует отдельное преобразование пароля. Здесь выбран API-ключ.
Параметры проверены по [официальной инструкции отправки](https://yandex.cloud/ru/docs/postbox/operations/send-email).

## Как передать настройки серверу

Ключи не отправлять в чат и не коммитить. Их подключение через защищённую
конфигурацию платформы подготовит агент после согласования реализации.
Точные имена параметров и путь секрета будут добавлены вместе с кодом;
сейчас не требуется создавать произвольные `.env` или выкладывать ключ в GitHub.
Для продолжения достаточно сообщить, что аккаунт и домен готовы.

Обычная разработка и Actions не требуют этого ключа: письма перехватывает
изолированный тестовый SMTP-приёмник. Настоящую доставку проверяют отдельно.

## Проверка перед включением регистрации

Отправить согласованные проверочные письма на собственные адреса владельца
в Gmail, Яндекс и Mail.ru. Проверить получение, папку спама, имя Aheadscale,
DKIM/SPF и соответствие DMARC. Принятие письма SMTP-сервером не является
подтверждением доставки. Ссылка должна открывать только HTTPS aheadscale.ru,
быть одноразовой и иметь срок действия; пароль в письме отсутствует.

Проверить срок ключа, процедуру замены, квоту и расходы по
[тарифам Postbox](https://yandex.cloud/ru/docs/postbox/pricing).
Первые 2 000 исходящих писем в календарном месяце не тарифицируются;
письма сверх этого объёма оплачиваются. Стоимость уточняется перед подключением.

[Начало работы с Postbox](https://yandex.cloud/ru/docs/postbox/quickstart).
