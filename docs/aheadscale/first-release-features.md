# Что можно делать с первой версией Aheadscale

Aheadscale объединяет ваши компьютеры и серверы в частную сеть. Вы устанавливаете клиент, входите в аккаунт и получаете доступ к подключённым устройствам по их именам — из дома, офиса или другой сети.

Документ описывает целевой состав первой стабильной версии для личного использования и малого офиса (SOHO). Пока идут испытания: доступность тестового установщика не означает, что стабильный выпуск для этой платформы уже готов. Состояние подготовки приведено в конце документа.

Обычный доступ в Интернет сохраняется через текущее подключение устройства; приватная сеть используется для связи с другими устройствами Aheadscale.

## Для кого первая версия

- **Для личного использования:** подключаться к своему компьютеру, серверу и файлам, находясь в другом месте.
- **Для специалистов:** работать с собственными серверами, средами разработки и внутренними сервисами.
- **Для малого офиса:** объединить рабочие устройства и серверы под управлением одного владельца аккаунта.

Базовая модель — **один аккаунт владельца и одна сеть его устройств**. На бесплатном тарифе планируется до пяти зарегистрированных устройств; временно выключенные устройства тоже занимают место. Неиспользуемое устройство можно удалить из панели, чтобы освободить место.

## Какие задачи можно решать

| Задача | Как помогает Aheadscale | Что нужно на самих устройствах |
| --- | --- | --- |
| **Подключиться к домашнему или рабочему компьютеру** | Даёт частный адрес и имя компьютера, по которым к нему обращается клиент удалённого рабочего стола | На целевом компьютере настроен поддерживаемый способ удалённого доступа, например RDP; на другом устройстве есть подходящая программа |
| **Управлять Linux-сервером через SSH** | Делает сервер доступным по приватному имени с других устройств аккаунта | На сервере работает SSH; для входа используются обычные учётные данные или SSH-ключи |
| **Работать с файлами на другом устройстве** | Позволяет открыть общую папку или передавать файлы через SMB/SFTP, используя приватный адрес либо имя | Общая папка или файловый сервис настроены, у пользователя есть необходимые права |
| **Открыть внутренний сайт или панель управления** | Даёт сетевой доступ к сервису, который работает на другом устройстве аккаунта | Сервис запущен и принимает подключения с нужного интерфейса; его собственная авторизация сохраняется |
| **Проверить своё приложение с другого компьютера** | Позволяет обращаться к тестовому приложению через частную сеть до его публикации | Тестовое приложение доступно по сетевому интерфейсу; оба компьютера подключены к аккаунту владельца |
| **Объединить устройства небольшого офиса** | Делает подключённые рабочие компьютеры и серверы доступными друг другу по приватным именам | На каждом участвующем устройстве установлен Aheadscale, необходимые рабочие сервисы настроены |

Например, в сеть можно включить ноутбук, домашний компьютер и Linux-сервер. На ноутбуке вы открываете рабочий стол компьютера, подключаетесь по SSH к серверу или загружаете файлы. Для каждой задачи используете привычную программу; Aheadscale обеспечивает соединение между устройствами.

Устройства и нужные сервисы должны быть включены. Если файловый сервер остановлен или локальный брандмауэр запрещает доступ к приложению, наличие VPN-соединения само по себе это не исправляет.

## Возможности приложения и их польза

| Возможность первой версии | Что получает пользователь |
| --- | --- |
| **Один установщик для рабочего компьютера** | Устанавливает приложение и фоновую службу вместе; отдельная настройка этих компонентов не требуется |
| **Сервер Aheadscale задан заранее** | Пользователь устанавливает клиент и входит в аккаунт; вводить адрес сервера или выбирать режим размещения не нужно |
| **Регистрация и вход через браузер** | Можно создать аккаунт по email либо войти доступным способом, включая подключённые VK ID и Яндекс ID; после входа подключение продолжается автоматически |
| **Автоматическое подключение** | Клиент настраивает частное сетевое соединение и восстанавливает его после перезапуска, пока регистрация действительна |
| **Каталог устройств** | Показывает имена, адреса и состояние устройств аккаунта; помогает найти нужное устройство и скопировать его данные |
| **Доступ по приватным именам** | Позволяет обращаться к серверу по понятному имени, не запоминая его IP-адрес |
| **Шифрование соединений** | Защищает передаваемые между устройствами данные; при возможности устройства соединяются напрямую, иначе используется промежуточный сервер с сохранением шифрования |
| **Переключатель подключения и понятный статус** | Позволяет включить или отключить сеть и увидеть состояние подключения. Отображение VPN в системной панели проверяется отдельно для каждой ОС |
| **Отдельный пакет командной строки (CLI) для Linux-серверов** | Позволяет подключать серверы без графического рабочего стола и без установки графического клиента |

Приватные имена и адреса берутся из каталога устройств. Они предназначены для обращения к устройствам внутри своей сети Aheadscale; это не публикация сервиса в Интернете.

## Как начать пользоваться

1. Скачайте установщик для своей ОС и архитектуры из доступного канала распространения Aheadscale.
2. Установите приложение и разрешите необходимые системные изменения.
3. Откройте Aheadscale, нажмите Connect и зарегистрируйтесь или войдите в браузере.
4. Подключите второе устройство к тому же аккаунту.
5. Найдите его имя в каталоге и используйте его в программе удалённого доступа, SSH, файловом клиенте или браузере.

Порядок установки и подсказки для тестовых сборок: [пользовательская инструкция](user-guide.md).

Для Linux-сервера без графического окружения предусмотрен отдельный сценарий регистрации. Вход должен завершаться с другого устройства либо с помощью ключа подключения; конкретный способ и команды будут опубликованы после проверки CLI-пакета. Переносить на такой сервер шаги графического клиента не требуется.

## Дополнительная возможность: профили

В состав первой версии **предлагается** включить необязательные профили для переключения между разными аккаунтами Aheadscale. Обычный пользователь продолжает работать с одним профилем; дополнительные создаются через настройки.

Например, один профиль может подключать компьютер к личному аккаунту, другой — к отдельному рабочему. При переключении прежнее соединение отключается, включается выбранное. На устройстве одновременно активен один профиль. Адрес сервера Aheadscale задаётся автоматически для каждого профиля.

Профиль сохраняет настройки и авторизацию подключения к существующему аккаунту. Создание профиля само по себе не создаёт новую независимую сеть внутри аккаунта.

**Текущее состояние:** в тестовых установщиках Aheadscale профили отключены. Их включение, удобство входа в нужный аккаунт и переключение на всех целевых ОС ещё требуется согласовать и проверить. Этот раздел описывает предложенную возможность, а не уже доступную функцию.

## Какие платформы готовим

| Платформа | Целевой вариант |
| --- | --- |
| Windows | Графический клиент для Windows 10/11 x64 и Windows 11 ARM64 |
| macOS | Графический клиент для Mac на Apple Silicon (ARM64) |
| Linux с рабочим столом | Графический клиент для Ubuntu и Fedora, x64 и ARM64 |
| Linux-сервер | Отдельный CLI-пакет, x64 и ARM64 |

Это целевая матрица первой версии. Точные поддерживаемые версии ОС и проверенные пакеты будут указаны при выпуске. В частности, Windows 10 требует проверки конкретной редакции и сборки; успешный тест Windows 11 ARM64 не подтверждает Windows x64. macOS Intel сейчас отложен и не входит в эту целевую матрицу.

Телефоны, планшеты, роутеры и специальные установщики для NAS не входят в текущую матрицу первой версии. Наличие похожего устройства в списке возможностей исходных компонентов не подтверждает поддержку дистрибутивом Aheadscale.

## Границы первой версии

Первая версия сосредоточена на доступе между устройствами одного владельца. Отдельные аккаунты сотрудников, приглашения в организацию, роли и выдача временного доступа подрядчикам относятся к следующему этапу. Сценарий SOHO в этом документе означает управление устройствами одним владельцем.

Также в дальнейшее развитие вынесены подключение целых офисных подсетей через шлюз, доступ к устройствам без установленного клиента, публикация сервисов для пользователей Интернета и выход всего интернет-трафика через выбранный VPN-узел.

Доступ по IP и приватному имени не означает автоматического обнаружения всех устройств «как по кабелю». Поиск принтеров, обнаружение медиасерверов, LAN-игры и пробуждение выключенного компьютера требуют отдельных проверок и здесь не заявляются готовыми сценариями.

## Состояние подготовки к выпуску

На 21 октября 2026 года подтверждены следующие части:

- На Ubuntu и Fedora ARM64 проверены тестовые графические пакеты, соединение между устройствами по IP и приватным именам, передача HTTP-данных и восстановление после перезапуска службы.
- На Fedora дополнительно проверена полная перезагрузка: фоновая служба и приложение запустились автоматически, регистрация сохранилась, системный VPN показал активное подключение. [Подробный отчёт](2026-10-21-linux-wireguard-port-fix.md).
- Системная VPN-интеграция Windows 11 ARM64 испытывалась в отдельных опытных сборках. Для стабильного выпуска требуется проверить весь путь через итоговый установщик на чистой системе.

macOS, Windows 10, варианты x64 и самостоятельные CLI-пакеты ещё предстоит проверить в принятом объёме. Успешные HTTP-проверки не заменяют прогоны RDP, SSH и файловых операций.

Перед публичным выпуском также должны пройти проверки изоляции аккаунтов, лимита устройств, подтверждения email и восстановления доступа, обновления и удаления приложения. Подпись установщиков, нотариализация macOS и собственное распространение обновлений входят в подготовку публичного выпуска. Профили оцениваются отдельно как предложенная дополнительная возможность.

Обоснование выбранных задач и направления дальнейшего развития: [исследование сценариев](tailscale-use-cases-and-release-scope.md).
