# Адресное исключение из лимита устройств

Запрос владельца 28 октября 2026 года: снять ограничение пяти устройств только
для его тестового аккаунта. У остальных аккаунтов бесплатный лимит сохраняется.

## Решение и границы

Оператор задаёт `AS_UNLIMITED_DEVICE_ACCOUNT_IDS` в окружении сервера: точные
внутренние ID аккаунтов, разделённые пробельными символами. Пустое значение —
исключений нет. `*`, email, префикс или подстрока ID не предоставляют исключение.
ID определяет оператор по серверной связи пользователя и аккаунта, а не клиент.
Список не доступен для редактирования через пользовательские настройки/API.

Для указанных аккаунтов отключается только проверка числа зарегистрированных
устройств в режиме `AS_SELF_REGISTRATION=true`. Авторизация, изоляция аккаунтов,
глобальная блокировка и транзакция регистрации сохраняются. Общий лимит не
повышается, существующие устройства не удаляются, схема SQLite не меняется.
Удаление ID из списка возвращает проверку при добавлении нового устройства;
уже зарегистрированные устройства сохраняются, даже если их больше пяти.
Изменение окружения требует пересоздания только контейнера сервера.

Рассмотренные варианты: глобальное повышение нарушает адресный запрос;
зашитый email привязывает код к персональным данным и не задаёт однозначный
аккаунт разных OAuth-провайдеров. Выбран список внутренних ID в конфигурации.

## Выполнение и проверка

1. На настоящем тестовом SQLite-хранилище добавить семь устройств исключённому
   аккаунту и попытаться добавить шестое обычному; также проверить отсутствие
   совпадения по префиксу и возврат лимита после удаления исключения.
2. Увидеть отказ исходного кода на шестом устройстве исключённого аккаунта;
   добавить точную проверку списка, затем повторить серверные регрессии.
3. Собрать сервер Go 1.26.7 с совместимой Linux runtime libc; сохранить
   неизменяемый image ID и настроить один подтверждённый ID в platform override.
4. Пересоздать только Aheadscale server с прежними конфигурацией и SQLite volume;
   проверить доступность, действующее исключение и сохранность устройств.
5. Сохранить исходники и эксплуатационную запись подписанными коммитами в main;
   удалить собственные промежуточные сборки/кэш. Клиентские пакеты не пересобирать.

Откат: вернуть прежний image ID и убрать переменную из server override, затем
пересоздать только сервер. Не откатывать и не удалять SQLite/учётные записи.
