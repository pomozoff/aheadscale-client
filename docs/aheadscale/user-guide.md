# Помощь Aheadscale

Инструкция предназначена для тестовых сборок. Первая стабильная версия ещё готовится. Задачи пользователей, целевой состав возможностей и состояние подготовки описаны в документе [«Что можно делать с первой версией Aheadscale»](first-release-features.md).

Aheadscale соединяет ваши компьютеры и серверы в частную сеть. Для первого подключения нужен клиент и аккаунт; адрес сервера уже задан в приложении.

## Установка и подключение

1. Откройте [панель Aheadscale](https://aheadscale.ru) и выберите установку клиента для своей платформы.
2. Установите Aheadscale и откройте приложение. На Linux для рабочего стола используйте пакет без суффикса `_cli`; вариант CLI предназначен для серверов.
3. Нажмите Connect. В браузере выберите Sign up для создания аккаунта или Sign in для входа; также доступны VK ID и Яндекс ID.
4. После входа вернитесь в приложение. Подключение продолжится автоматически.
5. Подключите другие устройства к тому же аккаунту.

Целевые платформы и архитектуры приведены в [описании первой версии](first-release-features.md#какие-платформы-готовим). Наличие установщика среди тестовых артефактов не подтверждает его стабильность на всех версиях ОС. Для испытаний выбирайте пакет, предназначенный для вашей платформы; точная матрица поддержки формируется по результатам проверок.

## Устройства и частные имена

На бесплатном этапе можно подключить до пяти устройств, включая временно выключенные. Список устройств показывает их имена и частные адреса. Используйте эти адреса или приватные DNS-имена для SSH, баз данных и внутренних сервисов.

Оба устройства должны быть подключены к одному аккаунту. Доступ к конкретному сервису также зависит от настроек самого сервиса, его порта и локального брандмауэра.

## Решение проблем

- Если браузер предлагает вход, а аккаунта ещё нет, выберите вкладку Sign up.
- Если устройство не появилось в списке, проверьте завершение входа в браузере и состояние подключения в клиенте.
- Если устройства подключены, но нужный сервис недоступен, проверьте его частный адрес, порт, работу сервиса и локальный брандмауэр.
- Если достигнут лимит устройств, удалите неиспользуемое устройство через панель.
- Для установки на сервер без графического окружения используйте CLI-пакет своей архитектуры.
