# Завершение первого входа в KDE

Согласовано владельцем 06.11.2026, AHEAD-15. Один агент, ветка codex/kde-autocomplete.

1. RED: настоящий D-Bus плагина возвращает готовность только текущей завершённой активации; Qt-диалог сам принимает текущую попытку, игнорирует старую и не оживает после Cancel. GUI ожидает завершения своей операции подключения.
2. Реализация: read-only проверка ID активации у закреплённого уникального владельца плагина. Асинхронный опрос привязан к жизни диалога; ошибки не означают успех. Подтверждение диалога передаёт прежние secrets и завершает стандартный протокол NetworkManager. Повторный запрос после отмены не допускается.
3. GREEN: целевые networkmanager и plasma Actions, затем нативная проверка окончательного пакета. Установщик и ARM-компонент не получают PASS по одному x64 тесту.

Таймауты, проверки origin, поколения, права и ручной Cancel сохраняются. Рабочий сервер не изменяется. Полная матрица выпуска остаётся отдельной задачей.
