Это ближайшие тестовые строки, а не обещанная совместимость со всеми версиями каждой ОС. Windows 7 исключена; Windows 10 ARM64 и macOS Intel сейчас не включаются. Для macOS нижняя граница ещё не принята: `LSMinimumSystemVersion=11.0` в упаковщике не доказывает работу на macOS 11. Более ранние Ubuntu/Fedora требуют отдельных строк проверки.

Объём CLI: все применимые C01–C24 [CLI-плана](cli-test-plan.md) для каждой целевой ОС/архитектуры. Команды, требующие GUI или конкретного backend, отмечаются отдельно; отсутствие headless-входа на Linux-сервере нельзя считать N/A. Поддержка стандартного Wintun и native Windows проверяется раздельно.

Упаковка RPM требует отдельной работы: в отчёте Fedora описан `--format rpm`, но в этой исходной точке и доступной истории такого параметра нет. ## Открытые пункты и зависимости

1. **Подтверждённое ограничение упаковки:** `package-desktop.py` отвергает любую архитектуру кроме `amd64`; ARM64 сейчас обновлялась компонентами. Устранить ограничение и не допускать смешивания x64/ARM64 либо разных исходных версий в одном EXE.
2. **Windows 10:** manifest и `desktop-install.ps1` требуют `10.0.26100.0` / build 26100. Не понижать эту границу только ради установки. Базовый [IVpnPlugIn](https://learn.microsoft.com/en-us/uwp/api/windows.networking.vpn.ivpnplugin) существует с Windows 10 build 10240, а [WebView2](https://learn.microsoft.com/en-us/microsoft-edge/webview2) поддерживает Windows 10: это основания проверить совместимость, а не доказательство поддержки нашего плагина. Отдельная ВМ/испытание ещё нужны.
3. **macOS, открытое наблюдение:** собственный VPN IPv4 не принимал локальное соединение на `.19`; на `.22` повтор ещё нужен. Первый TCP после обновления `.22` не прошёл, отдельный повтор прошёл; причина пока неизвестна.
4. **Отложенный разбор:** скорость подключения и восстановления. Выполнить позднее на прогретых ОС по P01–P06; не включать загрузку ОС/действия пользователя.
5. **Внешняя зависимость:** Apple Developer Program, Developer ID/нотаризация и подпись издателя Windows отсутствуют. Пакеты остаются preview. Отсутствие Network Extension macOS — открытое требование системного VPN.
6. **Непроведённые проверки:** полный GUI/CLI, чистый lifecycle, разные NAT/Relay и изоляция аккаунтов по общей матрице. Наличие сборки не закрывает эти пункты.
7. **Пробел исходников:** воспроизводимая RPM-упаковка отсутствует в текущем Git, хотя результат ручной сборки описан в отчёте Fedora. Сначала проверить возможность вернуть исходный сборщик из сохранённых материалов; затем закрепить его и проверить RPM. Этот пункт не закрывается новой сборкой DEB.

## Условия завершения этапов 1–2

- Матрица и эти ограничения сохранены; у Windows 10 и минимальной macOS нет необоснованного PASS.
- Есть единые Windows x64/ARM64 EXE с проверенным совпадением архитектуры, версии и исходного коммита компонентов.
- У каждого нового пакета записаны CI, commit, SHA256, состав и статус подписи; приёмка ещё отделена от факта сборки.
- Точные новые артефакты перечисляются здесь после успешной сборки, с отдельным результатом установки на ВМ. До этого новые версии не объявляются готовыми.
