## Открытые пункты и зависимости

1. **Ограничение Windows-упаковки устранено:** единые x64/ARM64 EXE `.23` построены и установлены; упаковщик отклоняет несовпадающие архитектуры, версии, исходные коммиты и хеши компонентов. Полная OS-приёмка остаётся открытой.
2. **Windows 10:** manifest и `desktop-install.ps1` требуют `10.0.26100.0` / build 26100. Не понижать эту границу только ради установки. Базовый [IVpnPlugIn](https://learn.microsoft.com/en-us/uwp/api/windows.networking.vpn.ivpnplugin) существует с Windows 10 build 10240, а [WebView2](https://learn.microsoft.com/en-us/microsoft-edge/webview2) поддерживает Windows 10: это основания проверить совместимость, а не доказательство поддержки нашего плагина. Отдельная ВМ/испытание ещё нужны.
3. **macOS:** собственный VPN IPv4 исправлен и принят в RG40 на `.25`. RG41 выявил перенаправление установки в перемещённый bundle; локальный preview PKG `.25.1` с явным запретом relocation прошёл переустановку. Полный lifecycle/чистая установка, системный VPN и подписи остаются открытыми.
4. **Отложенный разбор:** скорость подключения и восстановления. Выполнить позднее на прогретых ОС по P01–P06; не включать загрузку ОС/действия пользователя.
5. **Внешняя зависимость:** Apple Developer Program, Developer ID/нотаризация и подпись издателя Windows отсутствуют. Пакеты остаются preview. Отсутствие Network Extension macOS — открытое требование системного VPN.
6. **Непроведённые проверки:** полный GUI/CLI, чистый lifecycle, разные NAT/Relay и изоляция аккаунтов по общей матрице. Наличие сборки не закрывает эти пункты.
7. **Восстановление RPM:** исходные `rpm_package.py`, spec и unit найдены в сохранённом SDK-проекте 21 октября. Восстановлены отдельным изменением; реальные desktop/CLI RPM на синтетических ELF прошли проверку упаковки, состава и зависимостей. Это не клиентские RPM `.23` и не повтор Fedora smoke. Реальные ARM64 RPM/DEB из `0cc48b3` построены CI `40321330374`; обнаруженный неполный SHA-манифест исправлен в `b52f181`. Финальные Linux x64/ARM64 и macOS сборки из `b52f181` прошли, все файлы сверены с полным манифестом. Далее — новые RPM на ВМ.
