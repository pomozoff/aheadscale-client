# Права на управление службой в Linux

Если `aheadscale service start`, `stop` или `restart` завершилась отказом
в доступе, повторите её с административными правами, например:

```bash
sudo aheadscale service restart
```

При ошибке у обычного пользователя Linux CLI сохраняет исходное сообщение
системного менеджера и добавляет подсказку о `sudo`. Подсказка условная:
не каждая ошибка службы связана с правами. Если команда с `sudo` также
завершается ошибкой, нужно разбирать исходное сообщение и журнал службы.

Это не меняет права доступа, порядок запуска службы или код завершения.
В Windows и macOS эта Linux-подсказка не выводится.
